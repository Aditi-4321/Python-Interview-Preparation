## Question 17 — What is list comprehension?

### Answer

**List comprehension** is a concise Python syntax for creating a new list by applying an expression to each item of an iterable, optionally with a condition.

Instead of writing a complete `for` loop to build a list, list comprehension lets us express the same operation in a single readable statement.

### 1. Basic Syntax

```python
[expression for item in iterable]
```

With a condition:

```python
[expression for item in iterable if condition]
```

---

### 2. Basic Example

Suppose we want squares of numbers from 1 to 5.

Using a normal loop:

```python
squares = []

for x in range(1, 6):
    squares.append(x * x)

print(squares)
```

Output:

```text
[1, 4, 9, 16, 25]
```

Using list comprehension:

```python
squares = [x * x for x in range(1, 6)]

print(squares)
```

Output:

```text
[1, 4, 9, 16, 25]
```

The comprehension is shorter while still being readable.

---

### 3. List Comprehension with a Condition

We can filter elements using `if`.

For example, to get only even numbers:

```python
numbers = [1, 2, 3, 4, 5, 6]

even = [x for x in numbers if x % 2 == 0]

print(even)
```

Output:

```text
[2, 4, 6]
```

The general pattern is:

```python
[expression for item in iterable if condition]
```

Here:

* `x` → current element
* `x % 2 == 0` → filtering condition
* `x` → value placed into the new list

---

### 4. Transforming and Filtering Together

List comprehensions can perform both operations:

```python
numbers = [1, 2, 3, 4, 5, 6]

result = [x * x for x in numbers if x % 2 == 0]

print(result)
```

Output:

```text
[4, 16, 36]
```

The process is:

```text
Numbers → select even numbers → square them → create new list
```

---

### 5. Working with Strings

List comprehensions are useful for text processing too:

```python
words = ["python", "java", "sql"]

upper_words = [word.upper() for word in words]

print(upper_words)
```

Output:

```text
['PYTHON', 'JAVA', 'SQL']
```

---

### 6. Nested List Comprehension

A list comprehension can contain nested loops.

For example:

```python
pairs = [(x, y) for x in [1, 2] for y in [3, 4]]

print(pairs)
```

Output:

```text
[(1, 3), (1, 4), (2, 3), (2, 4)]
```

Conceptually, this is equivalent to:

```python
pairs = []

for x in [1, 2]:
    for y in [3, 4]:
        pairs.append((x, y))
```

Although nested comprehensions are valid, they should not be made unnecessarily complicated because readability is important.

---

### 7. Conditional Expression vs Filtering

A common interview confusion is the position of `if`.

**Filtering:**

```python
[x for x in numbers if x > 5]
```

Only values satisfying the condition are included.

**Conditional expression:**

```python
[x if x > 5 else 0 for x in numbers]
```

Every element is processed, but the output value depends on the condition.

Example:

```python
numbers = [2, 7, 4, 9]

result = [x if x > 5 else 0 for x in numbers]

print(result)
```

Output:

```text
[0, 7, 0, 9]
```

---

### 8. Time and Space Complexity

For a simple comprehension processing `n` elements:

* **Time:** generally O(n), assuming the expression itself is O(1)
* **Space:** O(n) for the resulting list

For example:

```python
squares = [x * x for x in numbers]
```

requires space for the new list.

This is important: list comprehensions are **not inherently more memory-efficient** than loops. They mainly provide concise syntax. If the complete list is not needed in memory, a **generator expression** may be more appropriate:

```python
squares = (x * x for x in numbers)
```

---

### 9. When Should You Use List Comprehension?

Use it when:

* You are creating a new list.
* The transformation/filtering logic is relatively simple.
* The resulting expression remains easy to read.

Avoid overly complex comprehensions such as multiple nested loops, complicated conditions, or large expressions. In those cases, a normal `for` loop may be clearer and easier to debug.

### Interview Takeaway

> **List comprehension is a concise way to create a new list by applying an expression to each element of an iterable, optionally filtering elements with a condition. It is usually O(n) for processing n elements and requires O(n) space for the resulting list.**

### Interview Follow-up

**Q: Is list comprehension faster than a normal `for` loop?**

It can be faster for many simple list-building operations because Python implements the comprehension efficiently, but the main benefit is **concise and readable code**, not guaranteed performance.

**Q: What should you use if you don't need the complete list in memory?**

A **generator expression** can be preferable because it produces values lazily instead of constructing the entire list at once.
