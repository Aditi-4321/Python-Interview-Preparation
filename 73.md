# Question 73 — How does Pandas differ from NumPy?

## Answer

**NumPy** and **Pandas** are both important Python libraries for data-related work, but they serve different primary purposes.

> **NumPy is primarily a numerical computing library based on multidimensional arrays, while Pandas is primarily a data manipulation and analysis library built around labeled, tabular data.**

A simple way to remember it:

```text
NumPy  → Numerical computation
Pandas → Data manipulation and analysis
```

---

## 1. NumPy

**NumPy (Numerical Python)** provides a powerful multidimensional array called `ndarray` and tools for numerical computation.

Example:

```python
import numpy as np

x = np.array([10, 20, 30, 40])

print(x.mean())
print(x * 2)
```

NumPy is commonly used for:

* Numerical calculations
* Arrays
* Matrix operations
* Linear algebra
* Statistical calculations
* Vectorization
* Broadcasting
* Numerical preprocessing

---

## 2. Pandas

**Pandas** is designed for working with structured and tabular data.

Its two fundamental data structures are:

* **Series** → one-dimensional labeled data
* **DataFrame** → two-dimensional labeled/tabular data

Example:

```python
import pandas as pd

data = {
    "Name": ["Aditi", "Rahul", "Neha"],
    "Marks": [85, 92, 78]
}

df = pd.DataFrame(data)

print(df)
```

Output:

```text
    Name  Marks
0  Aditi     85
1  Rahul     92
2   Neha     78
```

Pandas is commonly used for:

* Loading datasets
* Cleaning data
* Filtering
* Sorting
* Grouping
* Joining/merging
* Handling missing values
* Data transformation
* Exploratory data analysis

---

# 3. Main Difference

| Feature               | NumPy                     | Pandas                          |
| --------------------- | ------------------------- | ------------------------------- |
| Primary purpose       | Numerical computing       | Data manipulation and analysis  |
| Main structure        | `ndarray`                 | `Series`, `DataFrame`           |
| Data labeling         | Limited                   | Built-in                        |
| Tabular data          | Possible but basic        | Excellent                       |
| Numerical operations  | Excellent                 | Excellent, often built on NumPy |
| Missing data handling | More manual/general       | Rich built-in tools             |
| Grouping              | Limited/basic             | Powerful `groupby()`            |
| Data alignment        | Not label-based           | Automatic label-based alignment |
| Joins/merges          | Not its primary purpose   | Strong support                  |
| Typical use           | Numerical arrays/matrices | Real-world datasets/tables      |

---

# 4. NumPy Uses Arrays, Pandas Uses Labeled Data

Consider:

```python
x = np.array([80, 90, 70])
```

NumPy mainly focuses on the values and their positions.

With Pandas:

```python
marks = pd.Series(
    [80, 90, 70],
    index=["Aditi", "Rahul", "Neha"]
)
```

Now the values have meaningful labels.

```text
Aditi    80
Rahul    90
Neha     70
```

This labeling is extremely useful when working with real-world datasets.

---

# 5. DataFrames Are Designed for Tabular Data

Suppose we have a student dataset:

```text
Name     Age    Marks
Aditi    22     85
Rahul    23     92
Neha     21     78
```

Pandas can represent it naturally:

```python
df = pd.DataFrame({
    "Name": ["Aditi", "Rahul", "Neha"],
    "Age": [22, 23, 21],
    "Marks": [85, 92, 78]
})
```

You can then easily perform operations such as:

```python
df["Marks"].mean()
```

or:

```python
df[df["Marks"] > 80]
```

This type of labeled tabular manipulation is one of Pandas' major strengths.

---

# 6. Pandas Provides Rich Data Cleaning Operations

Real-world datasets often contain missing or incorrect values.

Pandas provides convenient operations such as:

```python
df.isna()
df.dropna()
df.fillna(0)
```

For example:

```python
df["Marks"] = df["Marks"].fillna(df["Marks"].mean())
```

This can replace missing marks with the column mean.

NumPy can also represent missing values in appropriate numerical arrays, but Pandas provides a broader set of table-oriented data-cleaning operations.

---

# 7. Pandas Provides Powerful Grouping

Suppose we have:

```text
Department    Salary
IT            50000
IT            60000
HR            45000
HR            55000
```

Pandas can calculate department-wise average salary:

```python
df.groupby("Department")["Salary"].mean()
```

This kind of **grouping and aggregation** is a common data-analysis task.

---

# 8. Pandas Provides DataFrame Operations

Pandas makes operations such as these convenient:

```python
df.sort_values("Marks")
```

```python
df.drop("Age", axis=1)
```

```python
df.rename(columns={"Marks": "Score"})
```

```python
df[df["Marks"] >= 80]
```

These operations are especially useful during exploratory data analysis and ML preprocessing.

---

# 9. Pandas Can Read Many Data Sources

Pandas provides convenient functions for loading data:

```python
pd.read_csv("data.csv")
```

```python
pd.read_excel("data.xlsx")
```

```python
pd.read_json("data.json")
```

It can also work with SQL databases through appropriate interfaces.

This makes Pandas very useful at the beginning of a data science or ML pipeline.

---

# 10. Relationship Between Pandas and NumPy

Pandas and NumPy are not competing libraries.

They often work together.

A simplified relationship is:

```text
          Pandas
        /         \
 Series           DataFrame
        \         /
           NumPy
              ↓
       Numerical Operations
```

Pandas uses NumPy extensively internally, although modern Pandas also supports other data representations and nullable data types.

For example:

```python
df["Marks"].to_numpy()
```

can give you the underlying values as a NumPy array.

# 11. Example in an ML Workflow

A typical workflow could look like:

```text
CSV Dataset
     ↓
Pandas
     ↓
Data Cleaning
     ↓
Exploratory Data Analysis
     ↓
Feature Selection
     ↓
NumPy / Pandas numerical operations
     ↓
scikit-learn
     ↓
ML Model
```

For example:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression

df = pd.read_csv("house_data.csv")

X = df[["area", "bedrooms"]]
y = df["price"]

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2
)

model = LinearRegression()
model.fit(X_train, y_train)
```

Here, Pandas is useful for loading and manipulating the structured dataset, while the ML library performs model training.

# 12. When Should You Use NumPy?

Use **NumPy** when your problem is primarily numerical.

Examples:

* Matrix calculations
* Numerical simulations
* Vectorized mathematical operations
* Linear algebra
* Working with homogeneous numerical arrays
* Scientific computing

Example:

```python
A = np.array([[1, 2], [3, 4]])

result = A @ A
```

---

# 13. When Should You Use Pandas?

Use **Pandas** when you are primarily working with structured or labeled data.

Examples:

* CSV/Excel datasets
* Data cleaning
* Filtering rows
* Selecting columns
* Grouping
* Joining tables
* Missing-value handling
* Exploratory data analysis
* Feature preparation

Example:

```python
df = pd.read_csv("customers.csv")

df = df.dropna()
df = df[df["age"] >= 18]
```

## Interview Follow-up

**Q: Which one should you learn first for ML?**

> Both are important. NumPy builds the foundation for numerical arrays and vectorized computation, while Pandas is especially useful for real-world data manipulation and analysis.

**Q: Is Pandas built on NumPy?**

> Historically and conceptually, Pandas has relied heavily on NumPy, particularly for numerical data and array operations. Modern Pandas also has its own data structures and supports additional data representations, so it is more accurate to say that Pandas is closely integrated with the NumPy ecosystem rather than simply being a thin wrapper around NumPy.

**Q: Can Pandas replace NumPy?**

> No. Pandas is specialized for labeled/tabular data manipulation, while NumPy provides a more general numerical array and scientific-computing foundation. They are often used together.

## Interview Takeaway

> **NumPy is primarily used for efficient numerical computation with multidimensional arrays, while Pandas is primarily used for labeled and tabular data manipulation and analysis. In an ML workflow, Pandas is commonly used to load, clean, explore, and transform datasets, while NumPy provides efficient numerical and array-based computation.**
