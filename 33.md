# Question 33 — What are higher-order functions such as `map()`, `filter()`, and `reduce()`?

## Answer

A **higher-order function** is a function that does at least one of the following:

1. **Takes another function as an argument**, or
2. **Returns another function**.

Python supports higher-order functions because functions are **first-class objects**.

Common examples include:

* `map()`
* `filter()`
* `reduce()`
* `sorted()` with a `key` function

`map()` and `filter()` are built-in functions, while `reduce()` is available from the `functools` module.

---

# 1. `map()`

`map()` applies a function to **every element** of an iterable.

### Syntax

```python
map(function, iterable)
```

### Example

```python
numbers = [1, 2, 3, 4]

squares = list(map(lambda x: x * x, numbers))

print(squares)
```

Output:

```text
[1, 4, 9, 16]
```

Conceptually:

```text
1 → 1 × 1 → 1
2 → 2 × 2 → 4
3 → 3 × 3 → 9
4 → 4 × 4 → 16
```

The lambda function is passed to `map()`, so `map()` is acting as a higher-order function.

### Important point

In Python 3, `map()` returns a **lazy iterator**, so the results are produced when iterated over. Using `list()` materializes all results in memory.

```python
result = map(lambda x: x * 2, numbers)
```

You can iterate over it:

```python
for value in result:
    print(value)
```

---

# 2. `filter()`

`filter()` selects elements from an iterable based on whether a function returns a truthy value.

### Syntax

```python
filter(function, iterable)
```

### Example

```python
numbers = [1, 2, 3, 4, 5, 6]

even_numbers = list(
    filter(lambda x: x % 2 == 0, numbers)
)

print(even_numbers)
```

Output:

```text
[2, 4, 6]
```

The lambda returns:

```text
True  → keep the element
False → discard the element
```

Like `map()`, `filter()` returns a **lazy iterator** in Python 3.

---

# 3. `reduce()`

`reduce()` repeatedly applies a function to elements of an iterable and reduces them to a **single accumulated result**.

It is available from `functools`.

```python
from functools import reduce
```

### Example

```python
from functools import reduce

numbers = [1, 2, 3, 4]

result = reduce(lambda a, b: a * b, numbers)

print(result)
```

Output:

```text
24
```

Conceptually:

```text
1 × 2 = 2
2 × 3 = 6
6 × 4 = 24
```

So the final result is:

```text
24
```

### With an initial value

`reduce()` can also accept an initializer:

```python
from functools import reduce

numbers = [1, 2, 3]

result = reduce(lambda a, b: a + b, numbers, 10)

print(result)
```

Output:

```text
16
```

The calculation is:

```text
10 + 1 + 2 + 3 = 16
```

# `map()` vs `filter()` vs `reduce()`

| Function   | Purpose                              | Result                         |
| ---------- | ------------------------------------ | ------------------------------ |
| `map()`    | Transform every element              | Iterable of transformed values |
| `filter()` | Select elements based on a condition | Iterable of selected values    |
| `reduce()` | Repeatedly combine elements          | Usually one final value        |

### Easy way to remember

```text
map    → Transform
filter → Select
reduce → Combine
```

For example:

```text
[1, 2, 3, 4]

map    → [2, 4, 6, 8]
filter → [2, 4]
reduce → 10
```

# Why Are They Called Higher-Order Functions?

Consider:

```python
def square(x):
    return x * x

numbers = [1, 2, 3, 4]

result = map(square, numbers)
```

Here, `square` itself is passed to `map()`.

Therefore:

```text
map()
  ↓
receives a function
  ↓
applies that function to data
```

This is the defining characteristic of a higher-order function.

Python also allows a function to **return another function**:

```python
def multiplier(n):
    def multiply(x):
        return x * n

    return multiply

double = multiplier(2)

print(double(5))
```

Output:

```text
10
```

Here, `multiplier()` returns the `multiply()` function.

# `map()` and List Comprehension

Many `map()` operations can also be written using list comprehensions.

### Using `map()`

```python
numbers = [1, 2, 3, 4]

squares = list(map(lambda x: x * x, numbers))
```

### Using list comprehension

```python
squares = [x * x for x in numbers]
```

The list comprehension is often easier to read for simple transformations.

Similarly:

```python
even_numbers = [x for x in numbers if x % 2 == 0]
```

can replace a simple `filter()` operation.

The choice depends on readability, the nature of the operation, and whether lazy iteration is useful.

# ML-Oriented Examples

Higher-order functions can be useful when processing data.

### Transforming values

```python
features = [10, 20, 30, 40]

scaled = list(map(lambda x: x / 10, features))

print(scaled)
```

Output:

```text
[1.0, 2.0, 3.0, 4.0]
```

### Selecting values

```python
scores = [45, 72, 88, 34, 91]

passed = list(filter(lambda x: x >= 50, scores))

print(passed)
```

Output:

```text
[72, 88, 91]
```

These are useful for simple transformations and filtering, although real ML pipelines commonly use **NumPy/Pandas vectorized operations** for numerical data because they can be clearer and more efficient for large datasets.

# Important Performance Point

`map()` and `filter()` are **lazy** in Python 3.

For example:

```python
result = map(lambda x: x * 2, numbers)
```

does not immediately create a complete list of results.

This can help with memory usage when processing large iterables:

```python
for value in map(lambda x: x * 2, numbers):
    print(value)
```

However, if you write:

```python
result = list(map(lambda x: x * 2, numbers))
```

the complete result is materialized in memory.

This distinction matters when processing large datasets.

## Common Mistakes

### 1. Forgetting that `map()` returns an iterator

```python
result = map(lambda x: x * 2, [1, 2, 3])

print(result)
```

This does not print the actual list of values. Use:

```python
print(list(result))
```

when you need to materialize the results.

### 2. Confusing `filter()` and `map()`

```text
map    → changes/transforms elements
filter → decides which elements to keep
```

### 3. Using `reduce()` when a simpler built-in exists

For example, instead of:

```python
from functools import reduce

total = reduce(lambda a, b: a + b, numbers)
```

prefer:

```python
total = sum(numbers)
```

when summing numbers. Built-in operations are generally clearer and often optimized.

---

## Interview Takeaway

> **A higher-order function is a function that accepts another function as an argument or returns a function. `map()` transforms every element, `filter()` selects elements based on a condition, and `reduce()` repeatedly combines elements to produce an accumulated result. In Python, `map()` and `filter()` return lazy iterators, while `reduce()` is provided by `functools`.**
