# Question 37 — What is inheritance?

## Answer

**Inheritance** is an Object-Oriented Programming (OOP) concept in which a **new class (child/subclass) derives properties and methods from an existing class (parent/base class)**.

In simple terms:

> **Inheritance allows a child class to reuse and extend the functionality of a parent class.**

It promotes **code reusability**, reduces duplication, and allows related classes to be organized in a hierarchy.

### Basic Example

```python
class Animal:
    def eat(self):
        print("Animal is eating")


class Dog(Animal):
    def bark(self):
        print("Dog is barking")


dog = Dog()

dog.eat()
dog.bark()
```

Output:

```text
Animal is eating
Dog is barking
```

Here:

* `Animal` is the **parent/base class**.
* `Dog` is the **child/derived class**.
* `Dog` inherits the `eat()` method from `Animal`.
* `Dog` also has its own `bark()` method.

So we can reuse the existing functionality without rewriting `eat()` inside `Dog`.

---

## Why is Inheritance Important?

### 1. Code Reusability

Common functionality can be defined once in a parent class and reused by multiple child classes.

### 2. Extensibility

A child class can add its own attributes and methods.

### 3. Method Overriding

A child class can provide its own implementation of a method inherited from the parent.

### 4. Hierarchical Organization

Inheritance can represent an **"is-a" relationship**.

For example:

```text
Animal
  |
  +-- Dog
  |
  +-- Cat
```

A dog **is an** animal, and a cat **is an** animal.

---

## Method Overriding

A child class can redefine a method inherited from its parent.

```python
class Animal:
    def sound(self):
        print("Some sound")


class Dog(Animal):
    def sound(self):
        print("Bark")


dog = Dog()
dog.sound()
```

Output:

```text
Bark
```

Although `sound()` exists in `Animal`, `Dog` provides its own implementation.

This is called **method overriding**.

---

## Using `super()`

Python provides `super()` to access functionality from the parent class.

```python
class Animal:
    def __init__(self, name):
        self.name = name


class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed


dog = Dog("Bruno", "Labrador")

print(dog.name)
print(dog.breed)
```

Here:

```python
super().__init__(name)
```

calls the parent class's `__init__()` method so that the inherited `name` attribute is initialized.

This is especially useful when the parent class has important initialization logic that the child class should reuse.

## Types of Inheritance in Python

Python supports several inheritance patterns.

### 1. Single Inheritance

One child class inherits from one parent class.

```text
A
|
B
```

```python
class A:
    pass


class B(A):
    pass
```

### 2. Multilevel Inheritance

Inheritance occurs across multiple levels.

```text
A
|
B
|
C
```

```python
class A:
    pass


class B(A):
    pass


class C(B):
    pass
```

### 3. Multiple Inheritance

A child class inherits from multiple parent classes.

```text
A     B
 \   /
   C
```

```python
class A:
    def method_a(self):
        print("A")


class B:
    def method_b(self):
        print("B")


class C(A, B):
    pass
```

`C` can access methods from both `A` and `B`.

### 4. Hierarchical Inheritance

Multiple child classes inherit from the same parent.

```text
      Animal
      /    \
    Dog    Cat
```

### 5. Hybrid Inheritance

A combination of two or more inheritance patterns.

## Method Resolution Order (MRO)

Multiple inheritance can create situations where Python needs to determine **which parent method should be used first**.

Python uses **Method Resolution Order (MRO)** to determine the order in which classes are searched.

You can inspect it using:

```python
print(C.mro())
```

Python uses the **C3 linearization** algorithm to calculate MRO.

For example:

```python
class A:
    pass


class B(A):
    pass


class C(A):
    pass


class D(B, C):
    pass


print(D.mro())
```

The MRO determines the order in which Python searches for attributes and methods.

## Inheritance in Machine Learning

Inheritance is commonly used in ML and deep-learning frameworks.

For example, in PyTorch, custom neural-network models commonly inherit from `torch.nn.Module`:

```python
import torch.nn as nn


class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer = nn.Linear(10, 1)

    def forward(self, x):
        return self.layer(x)
```

Here:

```python
class MyModel(nn.Module):
```

means `MyModel` inherits from `nn.Module`.

This allows the custom model to reuse functionality provided by PyTorch's `nn.Module`, such as parameter management and integration with the framework's model APIs.

## Inheritance vs Composition

Inheritance represents an **"is-a"** relationship.

```text
Dog is an Animal
```

Composition represents a **"has-a"** relationship.

```text
Car has an Engine
```

Example:

```python
class Engine:
    pass


class Car:
    def __init__(self):
        self.engine = Engine()
```

Here, `Car` uses an `Engine` object rather than inheriting from `Engine`.

In software design, composition is often preferred when the relationship is not naturally an "is-a" relationship.

---

## Common Mistakes

* Assuming inheritance is only about code reuse. It also establishes a relationship between classes.
* Confusing **inheritance** with **method overriding**. Inheritance provides the relationship/reuse; overriding replaces or specializes inherited behavior.
* Forgetting `super()` when parent initialization is required.
* Using inheritance when the relationship is actually **"has-a"** rather than **"is-a"**.
* In multiple inheritance, ignoring **MRO**, which determines method lookup order.
