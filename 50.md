# Question 50 — What is an iterator?

## Answer

An **iterator** is a Python object that produces elements **one at a time** and keeps track of its current position during iteration.

An iterator implements two methods:

* `__iter__()` — returns the iterator object itself.
* `__next__()` — returns the next element.

When there are no more elements, `__next__()` raises `StopIteration`.

### Simple mental model

> **An iterator is an object that remembers where it is and gives you the next item whenever you ask for it.**

---

## 1. Basic Example

A list is an iterable. We can create an iterator from it using `iter()`:

```python
numbers = [10, 20, 30]

it = iter(numbers)

print(next(it))  # 10
print(next(it))  # 20
print(next(it))  # 30
```

The iterator keeps track of its position:

```text
Initial
  ↓
10 → 20 → 30 → StopIteration
```

If we call `next()` again:

```python
print(next(it))
```

Python raises:

```text
StopIteration
```

because there are no more elements.

---

## 2. How Does `for` Use an Iterator?

When we write:

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)
```

Python internally obtains an iterator and repeatedly calls `next()` until `StopIteration`.

Conceptually, it is similar to:

```python
it = iter(numbers)

while True:
    try:
        number = next(it)
        print(number)
    except StopIteration:
        break
```

This is a simplified explanation of the iteration process.

Therefore:

```text
Iterable
   ↓ iter()
Iterator
   ↓ next()
Next element
   ↓ next()
Next element
   ↓
StopIteration
```

---

## 3. Iterable vs Iterator

This is one of the most important interview distinctions.

| Iterable                                            | Iterator                               |
| --------------------------------------------------- | -------------------------------------- |
| Can be iterated over                                | Produces elements one at a time        |
| Usually provides `__iter__()`                       | Provides `__iter__()` and `__next__()` |
| `iter(obj)` creates an iterator                     | `next(obj)` gets the next element      |
| Example: list, tuple, string                        | Example: `iter(list)`                  |
| Doesn't necessarily maintain iteration state itself | Maintains current iteration state      |

Example:

```python
numbers = [10, 20, 30]

print(hasattr(numbers, "__iter__"))  # True
print(hasattr(numbers, "__next__"))  # False
```

The list is an **iterable**, not an iterator.

Now:

```python
it = iter(numbers)

print(hasattr(it, "__iter__"))  # True
print(hasattr(it, "__next__"))  # True
```

`it` is an **iterator**.

### Key interview statement

> **Every iterator is iterable, but every iterable is not an iterator.**

## 4. Creating a Custom Iterator

We can create our own iterator by implementing `__iter__()` and `__next__()`.

```python
class Count:
    def __init__(self, limit):
        self.current = 1
        self.limit = limit

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= self.limit:
            value = self.current
            self.current += 1
            return value

        raise StopIteration


numbers = Count(3)

for x in numbers:
    print(x)
```

Output:

```text
1
2
3
```

### How it works

Initially:

```text
current = 1
```

First `next()`:

```text
return 1
current = 2
```

Second:

```text
return 2
current = 3
```

Third:

```text
return 3
current = 4
```

Next call:

```text
current > limit
       ↓
StopIteration
```

## 5. Why Are Iterators Useful?

The major advantage of iterators is that they can process data **incrementally** instead of requiring the entire sequence to be loaded into memory.

For example, consider a very large file:

```python
with open("large_file.txt", "r", encoding="utf-8") as file:
    for line in file:
        process(line)
```

The file object provides lines iteratively.

This is useful for:

* Large files
* Large datasets
* Data preprocessing
* Streaming data
* ML data pipelines
* Batch processing

Instead of:

```text
Load entire dataset
        ↓
Memory usage can become large
```

we can process:

```text
Read item/batch
      ↓
Process
      ↓
Read next item/batch
      ↓
Process
```

---

## 6. Iterator and Memory Efficiency

Consider creating a large list:

```python
numbers = [x for x in range(1000000)]
```

This creates and stores the complete list.

A lazy approach can produce values when needed:

```python
numbers = (x for x in range(1000000))
```

This is a **generator expression**, and the resulting generator is an iterator.

```python
print(next(numbers))
print(next(numbers))
```

Only the requested values are produced at that point.

This makes iterators particularly useful when working with large or potentially unbounded data.

---

## 7. Iterator vs Generator

A **generator is a convenient way to create an iterator**, usually using `yield`.

Example:

```python
def numbers():
    yield 1
    yield 2
    yield 3


it = numbers()

print(next(it))  # 1
print(next(it))  # 2
print(next(it))  # 3
```

The generator automatically manages much of the iterator state, so we don't need to manually implement `__iter__()` and `__next__()`.

### Difference

```text
Custom Iterator
→ Usually implements __iter__() and __next__() manually

Generator
→ Uses yield and Python manages the iterator state
```

For most simple lazy sequences, generators are easier to write.

---

## 8. Iterator State

An important property of an iterator is that it is **stateful**.

```python
numbers = [10, 20, 30]

it = iter(numbers)

print(next(it))  # 10
print(next(it))  # 20
```

At this point, the iterator remembers that `10` and `20` have already been consumed.

If we continue:

```python
print(next(it))  # 30
```

The iterator does not start from the beginning again.

To start a new iteration, create a new iterator:

```python
it2 = iter(numbers)

print(next(it2))  # 10
```

## 9. Iterator in ML/Data Processing

Iterators are very useful in machine learning pipelines where data may be too large to process all at once.

For example:

```python
def batches(data, size):
    for i in range(0, len(data), size):
        yield data[i:i + size]


data = [1, 2, 3, 4, 5, 6]

for batch in batches(data, 2):
    print(batch)
```

Output:

```text
[1, 2]
[3, 4]
[5, 6]
```

The generator produces batches on demand.

In real ML systems, similar ideas are used for:

* Mini-batch training
* Dataset loading
* Streaming preprocessing
* Large-scale data processing

Frameworks such as PyTorch also use iterable-style dataset/data-loading abstractions.

## Common Mistakes

### 1. Confusing iterable and iterator

A list is iterable:

```python
numbers = [1, 2, 3]
```

but it is not itself an iterator.

```python
next(numbers)  # TypeError
```

You first need:

```python
it = iter(numbers)
next(it)
```

### 2. Forgetting `StopIteration`

An iterator must signal that iteration has finished by raising `StopIteration`.

### 3. Assuming an iterator can always be restarted

Most iterators are stateful and become exhausted.

```python
it = iter([1, 2])

print(list(it))  # [1, 2]
print(list(it))  # []
```

A new iterator is needed for another complete traversal.

---

## Interview Takeaway

> **An iterator is an object that produces values one at a time and maintains its current state. It implements `__iter__()` and `__next__()`. `next()` retrieves the next value, and `StopIteration` indicates that the iterator is exhausted.**

### Remember This Relationship

```text
Iterable
   │
   │ iter()
   ↓
Iterator
   │
   │ next()
   ↓
Value → Value → Value
                 ↓
          StopIteration
```

**Key interview point:**

> **An iterable can provide an iterator, while an iterator actually produces the values one by one and maintains the iteration state.**
