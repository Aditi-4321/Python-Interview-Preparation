# Question 29 — Explain positional, keyword, default, `*args`, and `**kwargs` arguments.

## Answer

Python provides different ways to pass arguments to a function. The most common types are **positional arguments, keyword arguments, default arguments, `*args`, and `**kwargs`**.

---

## 1. Positional Arguments

In positional arguments, values are passed to parameters **according to their position/order**.

```python
def student(name, age):
    print(name, age)

student("Aditi", 22)
```

Here:

* `"Aditi"` → `name`
* `22` → `age`

The order matters.

```python
student(22, "Aditi")
```

This is valid Python, but the values are assigned incorrectly:

```text
name = 22
age = "Aditi"
```

### When to use?

Use positional arguments when the meaning of the arguments is clear from their order.

---

## 2. Keyword Arguments

In keyword arguments, we explicitly specify the **parameter name** while passing the value.

```python
def student(name, age):
    print(name, age)

student(age=22, name="Aditi")
```

The order does not matter because Python matches the values using parameter names.

```text
name = "Aditi"
age = 22
```

### Advantage

Keyword arguments improve readability, especially when a function has several parameters.

```python
train_model(epochs=20, learning_rate=0.01, batch_size=32)
```

It is much clearer than:

```python
train_model(20, 0.01, 32)
```

---

## 3. Default Arguments

A default argument gives a parameter a **default value** that is used when the caller does not provide that argument.

```python
def greet(name, message="Hello"):
    print(message, name)

greet("Aditi")
```

Output:

```text
Hello Aditi
```

If we provide the argument, the provided value replaces the default:

```python
greet("Aditi", "Welcome")
```

Output:

```text
Welcome Aditi
```

### Why are default arguments useful?

They make optional configuration easy.

For example:

```python
def train_model(epochs=10, learning_rate=0.001):
    print(epochs, learning_rate)
```

The caller can simply use:

```python
train_model()
```

or customize only what is needed:

```python
train_model(epochs=50)
```

### Important rule

Parameters with default values generally come **after required parameters**:

```python
def func(a, b=10):
    pass
```

But this is invalid:

```python
def func(a=10, b):
    pass
```

because a non-default parameter cannot follow a default parameter.

---

# 4. `*args`

`*args` allows a function to accept a **variable number of positional arguments**.

Inside the function, `args` is a **tuple**.

```python
def add_numbers(*args):
    total = 0

    for n in args:
        total += n

    return total

print(add_numbers(10, 20))
print(add_numbers(10, 20, 30, 40))
```

Output:

```text
30
100
```

The function can receive any number of positional arguments.

Conceptually:

```text
add_numbers(10, 20, 30)

args → (10, 20, 30)
```

The name `args` is conventional. The `*` is what provides the variable positional-argument behavior.

For example, this also works:

```python
def add_numbers(*numbers):
    return sum(numbers)
```

---

# 5. `**kwargs`

`**kwargs` allows a function to accept a **variable number of keyword arguments**.

Inside the function, `kwargs` is a **dictionary**.

```python
def show_details(**kwargs):
    print(kwargs)

show_details(name="Aditi", age=22, city="Lucknow")
```

Output:

```text
{'name': 'Aditi', 'age': 22, 'city': 'Lucknow'}
```

Conceptually:

```text
kwargs → {
    "name": "Aditi",
    "age": 22,
    "city": "Lucknow"
}
```

The name `kwargs` is conventional; the important part is `**`.

### ML-oriented example

```python
def create_model(**config):
    print(config)

create_model(
    algorithm="RandomForest",
    n_estimators=100,
    max_depth=5
)
```

This is useful when a function needs to accept flexible configuration options.

---

# `*args` vs `**kwargs`

| Feature   | `*args`                       | `**kwargs`                 |
| --------- | ----------------------------- | -------------------------- |
| Accepts   | Variable positional arguments | Variable keyword arguments |
| Stored as | Tuple                         | Dictionary                 |
| Uses      | `*`                           | `**`                       |
| Example   | `func(10, 20, 30)`            | `func(a=10, b=20)`         |

Simple memory trick:

```text
*args    → many positional values
**kwargs → many named values
```

---

# Using Them Together

A function can use normal parameters, `*args`, and `**kwargs` together.

```python
def demo(name, *args, **kwargs):
    print("Name:", name)
    print("Args:", args)
    print("Kwargs:", kwargs)

demo(
    "Aditi",
    10,
    20,
    city="Lucknow",
    course="MCA"
)
```

Output conceptually:

```text
Name: Aditi
Args: (10, 20)
Kwargs: {'city': 'Lucknow', 'course': 'MCA'}
```

Here:

* `name` → normal positional/keyword parameter
* `*args` → extra positional arguments
* `**kwargs` → extra keyword arguments

---

# Argument Order in a Function Definition

A commonly used ordering is:

```python
def func(required, default=10, *args, **kwargs):
    pass
```

For example:

```python
def process_data(name, version=1, *args, **kwargs):
    print(name)
    print(version)
    print(args)
    print(kwargs)
```

Python's full parameter system also includes **positional-only** (`/`) and **keyword-only** (`*`) parameters, but those are separate concepts from `*args`.

---

# Important: `*` and `**` Are Also Used for Unpacking

The same symbols can be used when **calling** a function.

### Unpacking a list/tuple with `*`

```python
def add(a, b, c):
    return a + b + c

numbers = [10, 20, 30]

print(add(*numbers))
```

Here:

```text
*numbers → 10, 20, 30
```

### Unpacking a dictionary with `**`

```python
def student(name, age):
    print(name, age)

data = {
    "name": "Aditi",
    "age": 22
}

student(**data)
```

Here:

```text
**data → name="Aditi", age=22
```

So remember:

```text
In definition:
*args     → collect extra positional arguments
**kwargs  → collect extra keyword arguments

In function call:
*list     → unpack positional values
**dict    → unpack keyword values
```

---

# Example Combining Different Argument Types

```python
def train_model(model, epochs=10, *metrics, **settings):
    print("Model:", model)
    print("Epochs:", epochs)
    print("Metrics:", metrics)
    print("Settings:", settings)

train_model(
    "RandomForest",
    50,
    "accuracy",
    "f1",
    learning_rate=0.01,
    max_depth=5
)
```

Conceptually:

```text
model    → "RandomForest"
epochs   → 50
metrics  → ("accuracy", "f1")
settings → {"learning_rate": 0.01, "max_depth": 5}
```

This pattern is useful when designing flexible APIs or utility functions, although in production code you should avoid making function interfaces unnecessarily vague.

## Common Mistakes

### 1. Confusing `*args` and `**kwargs`

```python
*args       → tuple
**kwargs    → dictionary
```

### 2. Thinking `args` and `kwargs` are special keywords

They are not. These names are conventions.

```python
def func(*values, **options):
    pass
```

works exactly the same way.

### 3. Mutable default arguments

Avoid:

```python
def add_item(item, items=[]):
    items.append(item)
    return items
```

The same list can be reused across calls, leading to unexpected behavior.

Prefer:

```python
def add_item(item, items=None):
    if items is None:
        items = []

    items.append(item)
    return items
```

This is a common Python interview topic.

---

## Interview Takeaway

> **Positional arguments are matched by order, keyword arguments are matched by parameter name, default arguments provide fallback values, `*args` collects variable positional arguments into a tuple, and `**kwargs` collects variable keyword arguments into a dictionary.**

### Interview Follow-up

**Q: What is the difference between `*args` and `**kwargs`?**
`*args` handles variable positional arguments and stores them as a tuple, while `**kwargs` handles variable keyword arguments and stores them as a dictionary.

**Q: Can positional and keyword arguments be mixed?**
Yes, but positional arguments must come before keyword arguments in a function call.

```python
def func(a, b, c):
    pass

func(10, 20, c=30)
```

**Q: What is the difference between `*args` in a function definition and `*list` in a function call?**
In a definition, `*args` **collects** positional arguments. In a call, `*list` **unpacks** an iterable into positional arguments.
