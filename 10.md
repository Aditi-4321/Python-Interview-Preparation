## Question 10 — What are string slicing and indexing?

### Answer

**Indexing** is used to access a single character from a string, while **slicing** is used to extract a portion of a string.

Python strings use **zero-based indexing**, meaning the first character is at index `0`.

---

### 1. String Indexing

Syntax:

```python
string[index]
```

Example:

```python
s = "Python"

print(s[0])
print(s[2])
print(s[5])
```

Output:

```text
P
t
n
```

The indexes are:

```text
String:   P  y  t  h  o  n
Index:    0  1  2  3  4  5
Negative: -6 -5 -4 -3 -2 -1
```

Python also supports **negative indexing**, where `-1` represents the last character.

```python
s = "Python"

print(s[-1])   # n
print(s[-2])   # o
```

Trying to access an index outside the valid range raises `IndexError`.

```python
print(s[10])
```

---

### 2. String Slicing

**Slicing** extracts a sequence of characters from a string.

Syntax:

```python
string[start:stop:step]
```

* `start` → index where slicing begins, included
* `stop` → index where slicing ends, **excluded**
* `step` → distance between selected characters; default is `1`

Example:

```python
s = "Python"

print(s[0:4])
```

Output:

```text
Pyth
```

The characters at indexes `0, 1, 2, 3` are included, while index `4` is excluded.

---

### 3. Common Slicing Examples

```python
s = "Python"

print(s[:4])      # Pyth
print(s[2:])      # thon
print(s[1:5])     # ytho
print(s[::2])     # Pto
print(s[::-1])    # nohtyP
```

When `start` or `stop` is omitted, Python automatically uses the appropriate beginning or end of the string.

The `[::-1]` pattern is commonly used to reverse a string.

---

### 4. Indexing vs Slicing

| Feature               | Indexing                    | Slicing                                 |
| --------------------- | --------------------------- | --------------------------------------- |
| Purpose               | Access one character        | Extract multiple characters             |
| Syntax                | `s[i]`                      | `s[start:stop:step]`                    |
| Result                | One-character string        | A new string                            |
| Example               | `s[2]`                      | `s[1:4]`                                |
| Out-of-range behavior | Usually raises `IndexError` | Usually returns an empty/shorter result |

For example:

```python
s = "Python"

print(s[2])      # t
print(s[1:4])    # yth
```

---

### 5. Important Point: Strings Are Immutable

Slicing does **not** modify the original string.

```python
s = "Python"

part = s[0:3]

print(s)
print(part)
```

Output:

```text
Python
Pyt
```

The original string remains unchanged, and the slice produces a separate string value.

---

### Practical Example

Suppose we have an email address:

```python
email = "aditi@example.com"

username = email[:email.index("@")]

print(username)
```

Output:

```text
aditi
```

Here, slicing can be used to extract the part before `@`.

### Interview Takeaway

> **Indexing accesses a single character using its position, while slicing extracts a range of characters using `start:stop:step`. Python uses zero-based indexing, supports negative indexes, and the stop index in slicing is exclusive.**

This is a common Python interview topic, so remember the simple rule: **indexing gets one character; slicing gets a portion of the string.**
