# Question 40 — What is method overriding?

## Answer

**Method overriding** is an OOP concept in which a **child class provides its own implementation of a method that is already defined in its parent class**.

In simple terms:

> **Method overriding allows a child class to change or specialize the behavior inherited from its parent class.**

It is commonly used to achieve **runtime polymorphism**.

### Basic Example

```python id="v5x2kp"
class Animal:
    def sound(self):
        print("Some animal sound")


class Dog(Animal):
    def sound(self):
        print("Bark")


animal = Animal()
dog = Dog()

animal.sound()
dog.sound()
```

Output:

```text id="r7k3mz"
Some animal sound
Bark
```

Here:

* `Animal` is the parent class.
* `Dog` is the child class.
* `sound()` is defined in `Animal`.
* `Dog` provides its own implementation of `sound()`.
* Therefore, `Dog.sound()` **overrides** `Animal.sound()`.

---

## Why is Method Overriding Important?

### 1. Specialization

A child class can provide behavior specific to that type of object.

### 2. Runtime Polymorphism

The method that executes can depend on the actual object.

```python id="h3w9qp"
animals = [Dog(), Animal()]

for animal in animals:
    animal.sound()
```

The same method call:

```python id="j8k2lm"
animal.sound()
```

can produce different behavior depending on the object.

### 3. Extensibility

Existing parent-class functionality can be customized without modifying the parent class.

### 4. Code Reusability

The child class can reuse other inherited methods while overriding only the behavior that needs to be different.

---

## Using `super()` with Method Overriding

Sometimes the child class wants to **extend** the parent's implementation instead of completely replacing it.

```python id="p4z7nc"
class Animal:
    def sound(self):
        print("Animal makes a sound")


class Dog(Animal):
    def sound(self):
        super().sound()
        print("Dog barks")


dog = Dog()
dog.sound()
```

Output:

```text id="m6q1vx"
Animal makes a sound
Dog barks
```

Here:

```python id="f2k8rs"
super().sound()
```

calls the parent class's version of `sound()`.

So the child class can add its own behavior while still reusing the parent's implementation.

---

## Method Overriding vs Method Overloading

These are commonly confused in interviews.

| Method Overriding                                          | Method Overloading                                                 |
| ---------------------------------------------------------- | ------------------------------------------------------------------ |
| Occurs between parent and child classes                    | Traditionally occurs within the same class                         |
| Child provides a new implementation of an inherited method | Multiple methods have the same name with different parameter lists |
| Used for specialization and runtime polymorphism           | Used to support different parameter combinations                   |
| Naturally supported in Python                              | Traditional compile-time overloading is not supported in Python    |

For example, overriding:

```python id="y7c4mx"
class Parent:
    def show(self):
        print("Parent")


class Child(Parent):
    def show(self):
        print("Child")
```

The `Child` implementation overrides the inherited `show()` method.

---

## Method Overriding in Machine Learning

Method overriding is frequently used when extending framework classes.

For example:

```python id="n8v3qt"
class BaseModel:
    def predict(self, x):
        raise NotImplementedError


class LinearModel(BaseModel):
    def predict(self, x):
        return "Linear prediction"


class TreeModel(BaseModel):
    def predict(self, x):
        return "Tree prediction"
```

Both `LinearModel` and `TreeModel` provide their own implementation of `predict()`.

A pipeline can then use:

```python id="q5r1ws"
models = [LinearModel(), TreeModel()]

for model in models:
    print(model.predict([1, 2, 3]))
```

The same `predict()` call produces model-specific behavior.

---

## Important Points

* The method name in the child class must correspond to the method being overridden.
* The child implementation replaces the inherited behavior when called on a child object.
* `super()` can be used when the child wants to reuse the parent's implementation.
* Overriding is closely related to **inheritance** and **polymorphism**.
* Python does not require a special keyword such as `override` for normal method overriding.

---

## Common Mistakes

* Confusing **overriding** with **overloading**.
* Thinking overriding means modifying the parent class itself. The parent class remains unchanged.
* Forgetting that `super()` is optional. It is needed only when the child wants to call/reuse parent behavior.
* Assuming overriding requires exactly the same parameter list in every Python situation; Python's dynamic nature provides flexibility, although compatible method interfaces are important for substitutability.

### Interview Takeaway

> **“Method overriding occurs when a child class provides its own implementation of a method inherited from a parent class. It allows subclasses to specialize behavior and is an important mechanism for runtime polymorphism. In Python, `super()` can be used to reuse the parent's implementation.”**
