These four methods are frequently asked in interviews because they cover common **text parsing, cleaning, transformation, and reconstruction** operations.

## Question 11 — What is the difference between common string methods such as `split()`, `join()`, `replace()`, and `strip()`?

### Answer

`split()`, `join()`, `replace()`, and `strip()` are commonly used Python string methods, but they perform different operations:

| Method      | Main purpose                              | Returns    |
| ----------- | ----------------------------------------- | ---------- |
| `split()`   | Breaks a string into parts                | List       |
| `join()`    | Combines multiple strings                 | String     |
| `replace()` | Replaces occurrences of text              | New string |
| `strip()`   | Removes characters from the beginning/end | New string |

All four methods work without modifying the original string because **strings are immutable**.

---

### 1. `split()` — String → List

`split()` divides a string into smaller parts based on a separator.

**Syntax:**

```python
string.split(separator, maxsplit)
```

Example:

```python
text = "Python is easy to learn"

words = text.split()

print(words)
```

Output:

```text
['Python', 'is', 'easy', 'to', 'learn']
```

If no separator is provided, Python splits on whitespace such as spaces, tabs, and newlines.

You can also specify a separator:

```python
data = "Java,Python,C++"

print(data.split(","))
```

Output:

```text
['Java', 'Python', 'C++']
```

**Practical use:** parsing CSV-like text, processing user input, tokenizing sentences, and extracting words.

---

### 2. `join()` — List/Iterable of Strings → String

`join()` combines multiple strings using a specified separator.

**Syntax:**

```python
separator.join(iterable)
```

Example:

```python
words = ["Python", "is", "easy"]

result = " ".join(words)

print(result)
```

Output:

```text
Python is easy
```

Another example:

```python
items = ["Java", "Python", "C++"]

result = ", ".join(items)

print(result)
```

Output:

```text
Java, Python, C++
```

An important point is that `join()` is called on the **separator**, not on the list:

```python
", ".join(items)
```

not:

```python
items.join(", ")   # AttributeError
```

All elements being joined should be strings:

```python
numbers = [1, 2, 3]

# ",".join(numbers)    # TypeError
```

If necessary:

```python
result = ",".join(map(str, numbers))
```

---

### 3. `replace()` — Replace Text

`replace()` replaces occurrences of one substring with another.

**Syntax:**

```python
string.replace(old, new, count)
```

Example:

```python
text = "I like Java"

result = text.replace("Java", "Python")

print(result)
```

Output:

```text
I like Python
```

You can optionally limit the number of replacements:

```python
text = "apple apple apple"

result = text.replace("apple", "orange", 2)

print(result)
```

Output:

```text
orange orange apple
```

**Practical use:** text cleaning, correcting known patterns, changing placeholders, and basic data preprocessing.

Important: `replace()` performs **literal substring replacement**. It is not a regular-expression operation. For pattern-based replacement, Python's `re` module can be used.

---

### 4. `strip()` — Remove Characters from the Ends

`strip()` removes leading and trailing whitespace by default.

```python
text = "   Hello Python   "

result = text.strip()

print(result)
```

Output:

```text
Hello Python
```

Related methods:

```python
text.lstrip()   # Removes from the left
text.rstrip()   # Removes from the right
text.strip()    # Removes from both sides
```

You can also specify characters:

```python
text = "---Python---"

print(text.strip("-"))
```

Output:

```text
Python
```

### Important Interview Point

`strip()` removes characters from the **beginning and end**, not from the middle.

```python
text = "Hello World"

print(text.strip("H"))
```

It does not remove `H` from arbitrary positions in the string.

Also, the argument to `strip()` is treated as a **set of characters**, not as an exact substring.

For example:

```python
text = "xyPythonyx"

print(text.strip("xy"))
```

This removes `x` and `y` characters from the ends until other characters are encountered.

---

### 5. `split()` and `join()` are Often Used Together

A common text-processing pattern is:

**String → split → process → join → String**

Example:

```python
text = "python is powerful"

words = text.split()
words = [word.upper() for word in words]

result = " ".join(words)

print(result)
```

Output:

```text
PYTHON IS POWERFUL
```

This pattern is useful in text preprocessing and data cleaning.

---

### Quick Comparison

```python
text = "  Python,Java,C++  "

# split()
print(text.strip().split(","))
# ['Python', 'Java', 'C++']

# join()
print(" | ".join(["Python", "Java", "C++"]))
# Python | Java | C++

# replace()
print(text.replace("Java", "Go"))
#   Python,Go,C++  

# strip()
print(text.strip())
# Python,Java,C++
```

### Interview Takeaway

> **`split()` breaks a string into a list, `join()` combines strings into one string, `replace()` substitutes one substring with another, and `strip()` removes specified characters—whitespace by default—from the beginning and end of a string.**

### Common Mistakes

* Thinking `split()` returns a string — it returns a **list**.
* Using `join()` on a list containing non-string values without converting them.
* Thinking `strip("abc")` removes the exact substring `"abc"` — it removes characters from the specified character set at the ends.
* Assuming `replace()` modifies the original string — it returns a **new string** because strings are immutable.

These four are especially useful to remember as a pipeline: **`strip()` cleans → `split()` separates → process → `join()` combines**, while **`replace()` transforms specific text**.
