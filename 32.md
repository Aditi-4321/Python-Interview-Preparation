# Question 32 — What are lambda functions?

## Answer

A **lambda function** is a small, anonymous function in Python that is usually used when a function is needed for a **short, simple operation**.

Unlike a normal function defined using `def`, a lambda function is defined using the `lambda` keyword and normally contains a **single expression**.

### Syntax

```python
lambda arguments: expression
```

The result of the expression is automatically returned.

### Example

Normal function:

```python
def square(x):
    return x * x
```

Equivalent lambda:

```python
square = lambda x: x * x

print(square(5))
```

Output:

```text
25
```

Here:

* `lambda` → keyword
* `x` → parameter
* `x * x` → expression
* The result of `x * x` is automatically returned.

---

# Why Are Lambda Functions Useful?

Lambda functions are useful when we need a **small function temporarily**, especially when passing a function as an argument to another function.

They are commonly used with:

* `sorted()`
* `map()`
* `filter()`
* `reduce()`
* callbacks and other APIs

---

## 1. Lambda with `sorted()`

Suppose we have students represented as tuples:

```python
students = [
    ("Aditi", 85),
    ("Rahul", 92),
    ("Priya", 78)
]
```

If we want to sort them by marks:

```python
students.sort(key=lambda student: student[1])

print(students)
```

Output:

```text
[('Priya', 78), ('Aditi', 85), ('Rahul', 92)]
```

Here:

```python
lambda student: student[1]
```

tells `sort()` to use the second element of each tuple as the sorting key.

The same logic using `def` would be:

```python
def get_marks(student):
    return student[1]

students.sort(key=get_marks)
```

For a small one-time operation, the lambda can be more concise.

---

## 2. Lambda with `map()`

`map()` applies a function to every item in an iterable.

```python
numbers = [1, 2, 3, 4]

squares = list(map(lambda x: x * x, numbers))

print(squares)
```

Output:

```text
[1, 4, 9, 16]
```

The lambda:

```python
lambda x: x * x
```

is applied to every number.

---

## 3. Lambda with `filter()`

`filter()` keeps elements for which the function returns a truthy value.

```python
numbers = [1, 2, 3, 4, 5, 6]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))

print(even_numbers)
```

Output:

```text
[2, 4, 6]
```

The lambda checks whether each number is even.

---

## 4. Lambda with `reduce()`

`reduce()` repeatedly combines elements to produce a single result.

It is available from the `functools` module.

```python
from functools import reduce

numbers = [1, 2, 3, 4]

result = reduce(lambda a, b: a * b, numbers)

print(result)
```

Output:

```text
24
```

The operation happens conceptually as:

```text
(((1 × 2) × 3) × 4)
```

For many simple reductions, built-in functions such as `sum()` or `math.prod()` can be clearer when applicable.

# Lambda with Multiple Arguments

A lambda can accept multiple parameters:

```python
add = lambda a, b: a + b

print(add(10, 20))
```

Output:

```text
30
```

The syntax is:

```python
lambda a, b: a + b
```

---

# Lambda with a Conditional Expression

A lambda can contain a conditional expression:

```python
check = lambda x: "Even" if x % 2 == 0 else "Odd"

print(check(10))
print(check(7))
```

Output:

```text
Even
Odd
```

However, if the logic becomes complicated, a normal `def` function is generally easier to read and maintain.

---

# Lambda vs Normal Function

| Feature          | Lambda                  | `def` Function                  |
| ---------------- | ----------------------- | ------------------------------- |
| Syntax           | `lambda`                | `def`                           |
| Usually named?   | Often anonymous         | Named                           |
| Body             | Single expression       | Can contain multiple statements |
| `return` keyword | Not normally used       | Can use `return`                |
| Best for         | Short/simple operations | Larger/reusable logic           |
| Documentation    | Less convenient         | Better                          |
| Debugging        | Can be less readable    | Usually easier                  |

### Example

Lambda:

```python
square = lambda x: x * x
```

Normal function:

```python
def square(x):
    return x * x
```

Both produce the same result.

---

# Important: Lambda Is Not Necessarily Faster

A common misconception is:

> "Lambda functions are faster than normal functions."

This is generally **not true**.

A lambda is primarily a different, more concise syntax for creating a function object. The main reason to use one is **convenience and readability for small operations**, not performance.

---

# ML-Oriented Example

Lambda functions can be useful when performing quick transformations or sorting operations on data.

For example, suppose model results are stored as:

```python
results = [
    ("Model A", 0.82),
    ("Model B", 0.91),
    ("Model C", 0.87)
]
```

To sort models by accuracy:

```python
results.sort(key=lambda x: x[1], reverse=True)
```

The lambda extracts the accuracy value, and `reverse=True` sorts from highest to lowest.

In larger ML pipelines, however, named functions are often preferable when the transformation is complex or reused multiple times.

## Common Mistakes

### 1. Trying to put multiple statements in a lambda

A lambda is designed around a **single expression**, not a sequence of statements.

For example, this is not valid:

```python
# Not valid
lambda x:
    y = x * 2
    return y
```

Use a normal function instead:

```python
def process(x):
    y = x * 2
    return y
```

### 2. Using lambda for complicated logic

This:

```python
result = lambda x: ...
```

can become difficult to understand if the expression is too complicated.

**Readability should come before making code shorter.**

### 3. Confusing lambda with a special type of function

A lambda creates a normal Python **function object**. The major difference is the concise syntax and restriction to a single expression.

---

## Interview Takeaway

> **A lambda function is a small anonymous function created using the `lambda` keyword. It takes zero or more arguments and contains a single expression whose result is automatically returned. It is commonly used with functions such as `sorted()`, `map()`, `filter()`, and `reduce()` for short operations.**

### Interview Follow-up

**Q: Can a lambda function have multiple arguments?**
Yes.

```python
lambda a, b: a + b
```

**Q: Can a lambda contain multiple statements?**
No. A lambda body is a single expression.

**Q: When should you prefer `def` over lambda?**
Use `def` when the logic is complex, reused, needs documentation, or would be clearer as a named function.

**Q: Is lambda faster than a normal function?**
Not inherently. Lambda is mainly a concise way to define a function; it should not be chosen primarily for performance.
