## Question 14 — What is a list and how does it differ from a tuple?

### Answer

A **list** is an ordered, mutable collection of objects in Python. A **tuple** is an ordered, immutable collection of objects.

Both can store multiple values and can contain elements of different data types.

### 1. List

A list is created using square brackets `[]`.

```python
numbers = [10, 20, 30, 40]

numbers[0] = 100

print(numbers)
```

Output:

```text
[100, 20, 30, 40]
```

Because lists are **mutable**, their elements can be added, removed, or changed after creation.

Common list operations:

```python
numbers.append(50)
numbers.remove(30)
numbers[1] = 200
```

---

### 2. Tuple

A tuple is created using parentheses `()`.

```python
numbers = (10, 20, 30, 40)
```

Tuples are **immutable**, so their elements cannot be changed after creation.

```python
numbers[0] = 100
```

This raises:

```text
TypeError: 'tuple' object does not support item assignment
```

A single-element tuple requires a trailing comma:

```python
x = (10,)    # tuple
y = (10)     # integer
```

---

### 3. Main Differences

| Feature              | List                       | Tuple                                |
| -------------------- | -------------------------- | ------------------------------------ |
| Syntax               | `[1, 2, 3]`                | `(1, 2, 3)`                          |
| Mutability           | Mutable                    | Immutable                            |
| Can modify elements? | Yes                        | No                                   |
| Can append/remove?   | Yes                        | No                                   |
| Hashable?            | No                         | Can be, if all elements are hashable |
| Typical use          | Collection that may change | Fixed collection/record-like data    |
| Methods              | More methods               | Fewer methods                        |

---

### 4. When should you use each?

Use a **list** when the collection needs to change:

```python
students = ["Aditi", "Rahul", "Neha"]

students.append("Aman")
```

For example, a list is appropriate for a collection of students whose membership may change.

Use a **tuple** when the collection represents fixed data:

```python
location = (26.8467, 80.9462)
```

A tuple can also be useful when you want to communicate that the collection itself should not be modified.

---

### 5. Both Support Indexing and Slicing

Both lists and tuples are ordered sequences:

```python
data = [10, 20, 30, 40]

print(data[1])     # 20
print(data[1:3])   # [20, 30]
```

```python
data = (10, 20, 30, 40)

print(data[1])     # 20
print(data[1:3])   # (20, 30)
```

Notice that slicing returns the **same sequence type**.

---

### 6. Important Tuple Nuance

A tuple itself is immutable, but it can contain a mutable object.

```python
data = ([1, 2], 10)

data[0].append(3)

print(data)
```

Output:

```text
([1, 2, 3], 10)
```

The tuple's element reference was not replaced. Instead, the **list inside the tuple was modified**.

However:

```python
data[0] = [4, 5]
```

is not allowed because that attempts to change the tuple itself.

---

### 7. Tuple as a Dictionary Key

A list cannot normally be used as a dictionary key because it is mutable and therefore unhashable:

```python
# data = {[1, 2]: "value"}   # TypeError
```

A tuple containing only hashable elements can be used:

```python
data = {
    (10, 20): "Point A"
}
```

This is useful when a fixed combination of values needs to act as a key.

---

### Interview Takeaway

> **A list is an ordered and mutable collection, while a tuple is an ordered and immutable collection. I would use a list when the data needs to change and a tuple when the collection should remain fixed or represents a fixed group of values.**

### Interview Follow-up

**Q: Is a tuple always hashable?**

No. A tuple is hashable only when all of its elements are hashable.

**Q: Which one should I use when data changes frequently?**

Generally, a **list**, because it is designed for mutable collections.

**Q: Are lists and tuples ordered?**

Yes. Both preserve element order and support indexing and slicing.
