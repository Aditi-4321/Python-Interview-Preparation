## Question 4 — What are Python's built-in data types?

### Answer

Python provides several **built-in data types** for representing numbers, text, collections, binary data, and other values.

The major built-in types can be grouped as follows:

| Category | Built-in Types                     | Example                      |
| -------- | ---------------------------------- | ---------------------------- |
| Numeric  | `int`, `float`, `complex`          | `10`, `3.14`, `2+3j`         |
| Boolean  | `bool`                             | `True`, `False`              |
| Text     | `str`                              | `"Hello"`                    |
| Sequence | `list`, `tuple`, `range`           | `[1,2]`, `(1,2)`, `range(5)` |
| Mapping  | `dict`                             | `{"name": "Aditi"}`          |
| Set      | `set`, `frozenset`                 | `{1,2,3}`                    |
| Binary   | `bytes`, `bytearray`, `memoryview` | `b"hello"`                   |
| Special  | `NoneType`                         | `None`                       |

---

## 1. Numeric Types

Python has three primary numeric types.

### `int`

Represents integers without a fixed size limit imposed by the language.

```python
age = 21
marks = -10
```

Python integers can represent arbitrarily large values, limited mainly by available memory.

```python
large_number = 12345678901234567890
```

### `float`

Represents floating-point numbers.

```python
price = 99.50
temperature = 36.5
```

Floating-point calculations are subject to the limitations of binary floating-point representation.

For example:

```python
print(0.1 + 0.2)
```

may produce:

```text
0.30000000000000004
```

This is not a Python bug; it results from how binary floating-point numbers are represented.

### `complex`

Represents complex numbers.

```python
z = 2 + 3j

print(z.real)  # 2.0
print(z.imag)  # 3.0
```

Here, `j` represents the imaginary component.

---

## 2. Boolean Type — `bool`

`bool` represents logical truth values:

```python
is_logged_in = True
is_admin = False
```

There are two Boolean values:

```python
True
False
```

`bool` is closely related to integers in Python: `True` behaves like `1` and `False` like `0` in numeric contexts.

```python
print(True + True)
```

Output:

```text
2
```

However, it is better to use Boolean values for logical conditions rather than treating them as ordinary integers.

---

## 3. Text Type — `str`

`str` represents Unicode text.

```python
name = "Aditi"
message = "Hello Python"
```

Strings are **immutable**.

```python
name = "Aditi"
```

You cannot modify an individual character of the existing string:

```python
# name[0] = "B"   # TypeError
```

Instead, a new string must be created.

```python
name = "B" + name[1:]
```

Strings support operations such as:

```python
text = "Python"

print(len(text))
print(text.upper())
print(text[0])
```

---

## 4. Sequence Types

### `list`

A list is an **ordered, mutable collection**.

```python
numbers = [10, 20, 30]
numbers.append(40)
```

Lists can contain different types:

```python
data = [10, "Python", 3.14, True]
```

Lists are commonly used when the collection needs to be modified.

---

### `tuple`

A tuple is an **ordered, immutable collection**.

```python
coordinates = (10, 20)
```

You cannot modify an existing tuple:

```python
# coordinates[0] = 50  # TypeError
```

Tuples are useful for representing fixed collections of values.

---

### `range`

`range` represents an immutable sequence-like object commonly used for iteration.

```python
numbers = range(5)

for number in numbers:
    print(number)
```

Output:

```text
0
1
2
3
4
```

An important point is that `range(5)` does not need to create a list containing all five integers.

---

## 5. Mapping Type — `dict`

A dictionary stores **key-value pairs**.

```python
student = {
    "name": "Aditi",
    "age": 21,
    "course": "MCA"
}
```

Values can be accessed using keys:

```python
print(student["name"])
```

Output:

```text
Aditi
```

Dictionaries are **mutable** and are widely used for structured data, configuration, API responses, and JSON-like data.

Modern Python dictionaries preserve **insertion order** as part of the language specification.

---

## 6. Set Types

### `set`

A set is a **mutable collection of unique elements**.

```python
numbers = {1, 2, 3, 3}

print(numbers)
```

The duplicate `3` is stored only once.

Sets are useful for:

* Removing duplicates
* Membership testing
* Mathematical set operations

For example:

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a & b)  # Intersection
print(a | b)  # Union
```

### `frozenset`

`frozenset` is an **immutable set**.

```python
numbers = frozenset([1, 2, 3])
```

Unlike a normal set, its elements cannot be added or removed.

---

## 7. Binary Types

Python provides three important built-in binary-related types.

### `bytes`

An immutable sequence of bytes.

```python
data = b"Hello"
```

### `bytearray`

A mutable sequence of bytes.

```python
data = bytearray(b"Hello")
data[0] = 74
```

### `memoryview`

Provides a view of the memory of another binary object without necessarily creating a new copy of the underlying data.

It can be useful when working with binary data efficiently.

---

## 8. `NoneType`

Python has a special value:

```python
None
```

Its type is:

```python
type(None)
```

which gives:

```text
<class 'NoneType'>
```

`None` generally represents **the absence of a value or a missing/undefined result**, rather than zero or an empty string.

Example:

```python
result = None

if result is None:
    print("No result available")
```

Use `is None` rather than `== None` when checking for `None`.

---

## Mutable vs Immutable Built-in Types

This is particularly important in interviews.

### Common mutable types

```text
list
dict
set
bytearray
```

Their contents can generally be changed after creation.

### Common immutable types

```text
int
float
complex
bool
str
tuple
range
bytes
frozenset
```

Their values cannot be modified after the object is created.

**Important:** Immutability applies to the object, not to the variable name referring to it.

---

## Quick Example

Consider:

```python
name = "Aditi"
age = 21
skills = ["Python", "Java"]
student = {
    "name": name,
    "age": age
}
```

The objects have different types:

```python
print(type(name))     # str
print(type(age))      # int
print(type(skills))   # list
print(type(student))  # dict
```

This illustrates how Python variables can refer to objects of different built-in types.

## Common Mistakes

### 1. Confusing list and tuple

```python
[1, 2, 3]   # list → mutable
(1, 2, 3)   # tuple → immutable
```

### 2. Thinking a set is ordered like a list

A set is primarily designed around **unique elements and set operations**, not positional indexing.

```python
numbers = {10, 20, 30}

# numbers[0]  # TypeError
```

### 3. Confusing `None`, `0`, and `False`

They are different values:

```python
None
0
False
```

Although some can evaluate as false in Boolean contexts, they have different meanings and types.

### 4. Assuming all collections are mutable

For example:

```python
list       # mutable
tuple      # immutable
set        # mutable
frozenset  # immutable
```

## Interview Takeaway

The most important built-in Python types to remember are:

```text
Numeric      → int, float, complex
Boolean      → bool
Text         → str
Sequence     → list, tuple, range
Mapping      → dict
Set          → set, frozenset
Binary       → bytes, bytearray, memoryview
Special      → NoneType
```

A strong interview response is:

> **Python provides built-in data types such as `int`, `float`, `complex`, `bool`, `str`, `list`, `tuple`, `range`, `dict`, `set`, `frozenset`, `bytes`, `bytearray`, `memoryview`, and `NoneType`. These types represent different kinds of data and have different properties. In particular, understanding which types are mutable and which are immutable is important for writing correct Python programs and avoiding unexpected behavior when objects are shared between variables.**
