F-strings are one of the most useful ways to format strings in modern Python and are commonly expected in coding interviews.

## Question 12 — What are f-strings and why are they useful?

### Answer

**F-strings (formatted string literals)** provide a concise way to insert variables and expressions directly into a string.

They are created by placing `f` or `F` before the opening quotation mark and putting expressions inside `{}`.

### 1. Basic Example

```python
name = "Aditi"
age = 22

message = f"My name is {name} and I am {age} years old."

print(message)
```

Output:

```text
My name is Aditi and I am 22 years old.
```

Python evaluates the expressions inside `{}` and inserts their results into the string.

---

### 2. Why are f-strings useful?

#### a. More readable

Instead of:

```python
name = "Aditi"
age = 22

print("My name is " + name + " and I am " + str(age))
```

we can write:

```python
print(f"My name is {name} and I am {age}")
```

The second version is easier to read and maintain.

---

#### b. Expressions can be used directly

F-strings are not limited to simple variables.

```python
a = 10
b = 20

print(f"Sum = {a + b}")
```

Output:

```text
Sum = 30
```

You can also access attributes and call methods:

```python
name = "python"

print(f"Uppercase: {name.upper()}")
```

Output:

```text
Uppercase: PYTHON
```

---

### 3. Formatting Numbers

F-strings support Python's format specification.

For example, formatting a floating-point value to two decimal places:

```python
price = 125.6789

print(f"Price: ₹{price:.2f}")
```

Output:

```text
Price: ₹125.68
```

Another common example is percentages:

```python
accuracy = 0.9567

print(f"Accuracy: {accuracy:.2%}")
```

Output:

```text
Accuracy: 95.67%
```

This is particularly useful when displaying **ML model metrics, reports, prices, or calculated values**.

---

### 4. Formatting and Alignment

F-strings can also control width and alignment:

```python
name = "Python"

print(f"{name:>10}")
print(f"{name:<10}")
print(f"{name:^10}")
```

Here:

* `>` → right-align
* `<` → left-align
* `^` → center-align

This can be useful when generating simple tabular output.

---

### 5. Debugging with `=`

A useful feature is the `=` syntax:

```python
x = 10
y = 20

print(f"{x=}, {y=}, {x+y=}")
```

Output:

```text
x=10, y=20, x+y=30
```

This is convenient for quick debugging.

---

### 6. F-Strings vs Older Formatting Methods

#### String concatenation

```python
name = "Aditi"
age = 22

message = "Name: " + name + ", Age: " + str(age)
```

#### `.format()`

```python
message = "Name: {}, Age: {}".format(name, age)
```

#### F-string

```python
message = f"Name: {name}, Age: {age}"
```

F-strings are generally preferred for straightforward formatting because they keep the values close to where they appear in the resulting text.

---

### 7. Important Security Point

F-strings evaluate Python expressions inside `{}`. Therefore, **never treat untrusted user input as Python code and dynamically construct an f-string expression from it**.

For normal usage, putting trusted variables into an f-string is perfectly fine:

```python
username = input("Enter username: ")

message = f"Welcome, {username}"
```

Here, the input is inserted as a value; it is **not executed as Python code**.

---

### Interview Takeaway

> **F-strings are formatted string literals that allow variables and expressions to be embedded directly inside strings using `{}`. They improve readability, reduce unnecessary concatenation or conversions, and support powerful formatting such as decimal precision, percentages, alignment, and debugging expressions.**

### Interview Follow-up

**Q: What is the syntax for an f-string?**

```python
f"Hello {name}"
```

**Q: Can expressions be used inside an f-string?**

Yes.

```python
f"Total = {price * quantity}"
```

**Q: Are f-strings only for variables?**

No. They can contain valid Python expressions, attribute access, method calls, and formatting specifications.
