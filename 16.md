## Question 16 — What is list slicing?

### Answer

**List slicing** is a way to extract a portion of a list using the syntax:

```python
list[start:stop:step]
```

* `start` → index where slicing begins (**included**)
* `stop` → index where slicing ends (**excluded**)
* `step` → interval between selected elements; default is `1`

### 1. Basic Example

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])
```

Output:

```text
[20, 30, 40]
```

Indexes:

```text
Value:   10   20   30   40   50
Index:    0    1    2    3    4
```

The slice `1:4` selects indexes `1`, `2`, and `3`; index `4` is excluded.

---

### 2. Omitting Start or Stop

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[:3])    # [10, 20, 30]
print(numbers[2:])    # [30, 40, 50]
print(numbers[:])     # [10, 20, 30, 40, 50]
```

* `[:3]` → from the beginning up to index `3`
* `[2:]` → from index `2` to the end
* `[:]` → entire list

---

### 3. Using Step

The third value controls how many positions Python moves each time.

```python
numbers = [10, 20, 30, 40, 50, 60]

print(numbers[::2])
```

Output:

```text
[10, 30, 50]
```

It selects every second element.

Another example:

```python
print(numbers[1::2])
```

Output:

```text
[20, 40, 60]
```

---

### 4. Negative Indexing and Reversing

Python supports negative indexes:

```text
Value:       10   20   30   40   50
Positive:     0    1    2    3    4
Negative:    -5   -4   -3   -2   -1
```

Therefore:

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[-3:])
```

Output:

```text
[30, 40, 50]
```

A negative step can be used to reverse a list:

```python
print(numbers[::-1])
```

Output:

```text
[50, 40, 30, 20, 10]
```

---

### 5. Slicing Creates a New List

This is an important interview point.

```python
numbers = [10, 20, 30, 40]

part = numbers[1:3]

part[0] = 200

print(part)
print(numbers)
```

Output:

```text
[200, 30]
[10, 20, 30, 40]
```

The slice creates a **new list**, so modifying the sliced list does not modify the original list at the top level.

A full slice is therefore often used as a **shallow copy**:

```python
copy = numbers[:]
```

However, it is not a deep copy if the list contains mutable nested objects.

---

### 6. Slice Assignment

Python also allows assigning to a slice:

```python
numbers = [10, 20, 30, 40]

numbers[1:3] = [200, 300]

print(numbers)
```

Output:

```text
[10, 200, 300, 40]
```

Unlike normal slicing, **slice assignment modifies the original list**.

It can even change the list's length:

```python
numbers[1:3] = [200, 300, 400, 500]

print(numbers)
```

Output:

```text
[10, 200, 300, 400, 500, 40]
```

---

### 7. Time and Space Complexity

If a slice contains `k` elements:

* **Time complexity:** O(k)
* **Additional space:** O(k)

This is because Python creates a new list and copies references to the selected elements.

Therefore, repeatedly slicing extremely large lists can create unnecessary memory and performance overhead.

### Interview Takeaway

> **List slicing extracts a portion of a list using `start:stop:step`. The start index is included, the stop index is excluded, and the step controls how elements are selected. Normal slicing creates a new list, while slice assignment modifies the original list.**

### Common Mistakes

* Forgetting that the **stop index is exclusive**.
* Assuming `a[:]` is a deep copy—it is only a **shallow copy**.
* Assuming slicing modifies the original list—it normally does not.
* Forgetting that a negative step can be used to traverse the list backwards.
