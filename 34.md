# Question 34 — What are classes and objects?

## Answer

**Classes and objects are the foundation of Object-Oriented Programming (OOP) in Python.**

A **class** is a blueprint or template that defines the **data (attributes)** and **behavior (methods)** that its objects will have.

An **object** is a specific instance created from a class.

### Simple analogy

Think of a class as a **blueprint for a house**:

```text
Class  → House blueprint
Object → Actual house built from that blueprint
```

The blueprint defines what the house can have, while each actual house can have its own values.

---

# 1. What is a Class?

A class is created using the `class` keyword.

```python id="c2x4ha"
class Student:
    pass
```

Here, `Student` is a class.

We can add attributes and methods to it:

```python id="q9s7vl"
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print("My name is", self.name)
```

Here:

* `Student` → class
* `name` and `age` → instance attributes
* `introduce()` → method
* `__init__()` → initializer called when an instance is created
* `self` → reference to the current instance

---

# 2. What is an Object?

An object is an **instance of a class**.

```python id="4s7x2c"
student1 = Student("Aditi", 22)
student2 = Student("Rahul", 23)
```

Here:

```text id="f4a1nw"
Student → Class

student1 → Object
student2 → Object
```

Both objects belong to the same class, but they contain different data.

```python id="9x2k7a"
print(student1.name)
print(student2.name)
```

Output:

```text id="z8s6pc"
Aditi
Rahul
```

---

# 3. Attributes and Methods

Objects generally contain **state** and **behavior**.

### Attributes → Data/State

```python id="m8h0q1"
student1.name
student1.age
```

These describe the object.

### Methods → Behavior

```python id="j7s4w2"
student1.introduce()
```

This represents an action the object can perform.

So:

```text id="7x4v2p"
Object
 ├── Attributes → what it has
 └── Methods    → what it does
```

---

# 4. The `__init__()` Method

`__init__()` is an initializer that Python calls when an instance is created.

```python id="d5y7q2"
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

When we write:

```python id="8v5m1c"
student = Student("Aditi", 22)
```

Python creates a `Student` instance and calls `__init__()` to initialize its attributes.

Conceptually:

```text id="1f3p9x"
Student("Aditi", 22)
        ↓
__init__(self, "Aditi", 22)
        ↓
self.name = "Aditi"
self.age = 22
```

---

# 5. What is `self`?

`self` refers to the **current object/instance**.

```python id="p0k3x8"
class Student:
    def __init__(self, name):
        self.name = name

    def show(self):
        print(self.name)
```

When we call:

```python id="b8w2n5"
student = Student("Aditi")
student.show()
```

`self` refers to `student` during that method call.

This allows each object to maintain its own data.

```python id="g4r1w6"
student1 = Student("Aditi")
student2 = Student("Rahul")
```

Conceptually:

```text id="j1s7k9"
student1 → self.name = "Aditi"
student2 → self.name = "Rahul"
```

### Important point

`self` is not a Python keyword like `if` or `class`. It is the conventional name for the first parameter of an instance method.

# 6. Multiple Objects

A single class can create many objects.

```python id="v8p2m4"
class Car:
    def __init__(self, brand, model):
        self.brand = brand
        self.model = model

car1 = Car("Toyota", "Camry")
car2 = Car("Honda", "City")
```

Both are `Car` objects:

```text id="x0j5s8"
Car
├── car1 → Toyota, Camry
└── car2 → Honda, City
```

Changing one object's attribute does not normally change the other object's instance attribute:

```python id="1c6x9m"
car1.model = "Corolla"

print(car1.model)
print(car2.model)
```

Output:

```text id="5x0s7d"
Corolla
City
```

---

# Class vs Object

| Class                                    | Object                                 |
| ---------------------------------------- | -------------------------------------- |
| Blueprint/template                       | Instance of a class                    |
| Defines attributes and methods           | Contains actual values/state           |
| Does not represent one specific instance | Represents a specific instance         |
| Example: `Student`                       | Example: `student1`                    |
| One class can create many objects        | Each object has its own instance state |

### Easy way to remember

> **Class = blueprint**
> **Object = actual instance**

# Why Are Classes and Objects Important?

### 1. Organization

They group related **data and behavior** together.

### 2. Reusability

One class can be used to create many objects.

### 3. Encapsulation

A class provides a structured way to manage an object's state and operations.

### 4. Maintainability

Large programs can be divided into meaningful components.

### 5. Modeling Real-World Entities

For example, in a software application we might have:

```text id="5g8v2k"
User
Product
Order
Payment
Model
Dataset
```

Each can be represented using classes.

# Classes and Objects in AI/ML

Classes are heavily used in ML libraries.

For example, in scikit-learn:

```python id="z3k8w1"
from sklearn.linear_model import LinearRegression

model = LinearRegression()
```

Here:

```text id="a6v4r2"
LinearRegression → Class
model            → Object/Instance
```

We can then use methods on the object:

```python id="q8m1s5"
model.fit(X_train, y_train)

predictions = model.predict(X_test)
```

The object maintains the model's learned state after training.

Similarly, in PyTorch:

```python id="e7x3n9"
import torch.nn as nn

model = nn.Linear(10, 1)
```

`nn.Linear` is a class, and `model` is an instance of that class.

This is one reason understanding OOP is important for AI/ML development.

# Common Mistakes

### 1. Confusing class and object

```python id="m3k9q2"
class Student:
    pass

student = Student()
```

Here:

```text id="3s7w1p"
Student → class
student → object
```

### 2. Confusing attributes and methods

```python id="x6j4r8"
student.name       # attribute
student.introduce() # method
```

Attributes represent data/state, while methods represent behavior.

### 3. Thinking `self` creates a new object

`self` does not create an object. It refers to the current instance on which the method is being called.

## Interview Takeaway

> **A class is a blueprint that defines the attributes and methods of a type, while an object is a specific instance of that class. Classes help organize and reuse related data and behavior, and objects maintain their own instance state. OOP is widely used in Python libraries such as scikit-learn and PyTorch.**

### Interview Follow-up

**Q: What is the difference between a class and an object?**
A class is a blueprint/template, while an object is an instance created from that class.

**Q: What is `self` in Python?**
`self` is the conventional reference to the current instance and allows instance methods to access that object's attributes and other methods.

**Q: Is `__init__()` a constructor in Python?**
It is commonly called a constructor informally, but more precisely, `__new__()` is responsible for creating the instance, while `__init__()` initializes an already-created instance.
