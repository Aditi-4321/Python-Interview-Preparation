# Question 26 — Explain if, elif, else, for, and while.

## Answer

`if`, `elif`, and `else` are used for **decision-making**, while `for` and `while` are used for **repetition/loops** in Python.

A simple way to remember them:

```text
if / elif / else → "Which block should execute?"
for / while      → "How many times should it execute?"
```

---

# 1. `if` Statement

The `if` statement executes a block of code **only when a condition is `True`**.

### Syntax

```python
if condition:
    # code
```

### Example

```python
age = 20

if age >= 18:
    print("Eligible")
```

Output:

```text
Eligible
```

If the condition is `False`, the block is skipped.

```python
age = 16

if age >= 18:
    print("Eligible")
```

No output is produced.

### Why use `if`?

Use `if` when some code should execute only when a particular condition is satisfied.

---

# 2. `else` Statement

`else` provides an alternative block when the `if` condition is `False`.

```python
age = 16

if age >= 18:
    print("Eligible")
else:
    print("Not eligible")
```

Output:

```text
Not eligible
```

The `else` block does not have its own condition. It executes when the preceding `if` condition is false.

---

# 3. `elif` Statement

`elif` means **"else if"**.

It allows us to check multiple conditions.

```python
marks = 75

if marks >= 90:
    grade = "A"
elif marks >= 75:
    grade = "B"
elif marks >= 60:
    grade = "C"
else:
    grade = "D"

print(grade)
```

Output:

```text
B
```

Python checks the conditions from **top to bottom** and executes the first matching block.

### Important

Once a condition is found to be `True`, the remaining `elif` and `else` blocks are skipped.

---

# 4. `if-elif-else` Flow

The flow can be visualized as:

```text
             Condition 1?
              /       \
           True       False
            ↓           ↓
        Execute      Condition 2?
                       /      \
                    True      False
                     ↓          ↓
                  Execute    Condition 3?
                               /     \
                            True     False
                             ↓         ↓
                          Execute    else
```

This makes `if-elif-else` useful for mutually exclusive decisions.

---

# 5. `for` Loop

A `for` loop is used to **iterate over the elements of an iterable**.

An iterable can be a:

* List
* Tuple
* String
* Set
* Dictionary
* Range
* Generator
* Many other iterable objects

### Example

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)
```

Output:

```text
10
20
30
```

The loop takes each element one by one and executes the loop body.

---

## `for` with `range()`

`range()` is commonly used when we need a sequence of numbers.

```python
for i in range(5):
    print(i)
```

Output:

```text
0
1
2
3
4
```

Remember:

```python
range(5)
```

generates values from `0` up to, but not including, `5`.

We can also specify start and step:

```python
for i in range(1, 10, 2):
    print(i)
```

Output:

```text
1
3
5
7
9
```

---

# 6. `for` Loop with a Dictionary

When iterating over a dictionary directly, Python iterates over its **keys**:

```python
marks = {
    "Python": 90,
    "Java": 85
}

for subject in marks:
    print(subject)
```

Output:

```text
Python
Java
```

To get both keys and values:

```python
for subject, mark in marks.items():
    print(subject, mark)
```

Output:

```text
Python 90
Java 85
```

---

# 7. `while` Loop

A `while` loop repeatedly executes code **as long as its condition remains `True`**.

### Syntax

```python
while condition:
    # code
```

### Example

```python
i = 1

while i <= 5:
    print(i)
    i += 1
```

Output:

```text
1
2
3
4
5
```

Here:

1. `i` starts at `1`.
2. Python checks `i <= 5`.
3. The loop executes.
4. `i` is increased.
5. The condition is checked again.
6. The loop stops when the condition becomes `False`.

---

# 8. `for` vs `while`

| Feature               | `for`                                 | `while`                             |
| --------------------- | ------------------------------------- | ----------------------------------- |
| Main use              | Iterate over an iterable              | Repeat while a condition is true    |
| Common use            | Lists, strings, ranges, generators    | Condition-controlled repetition     |
| Number of iterations  | Often known or determined by iterable | May not be known beforehand         |
| Risk of infinite loop | Lower                                 | Higher                              |
| Example               | Process every row                     | Continue until user enters `"exit"` |

### Example use of `for`

```python
for student in students:
    process(student)
```

We want to process every student.

### Example use of `while`

```python
while not_model_ready:
    check_status()
```

We want to continue until a condition changes.

---

# 9. `break`

`break` immediately terminates the loop.

```python
for number in range(10):
    if number == 5:
        break
    print(number)
```

Output:

```text
0
1
2
3
4
```

When `number` becomes `5`, the loop stops.

---

# 10. `continue`

`continue` skips the **current iteration** and moves to the next iteration.

```python
for number in range(5):
    if number == 2:
        continue
    print(number)
```

Output:

```text
0
1
3
4
```

The iteration where `number == 2` is skipped.

---

# 11. `else` with Loops

Python also allows `else` with `for` and `while`.

The loop's `else` block executes when the loop finishes **normally**, without encountering `break`.

Example:

```python
for number in range(5):
    if number == 10:
        break
else:
    print("Number not found")
```

Output:

```text
Number not found
```

But:

```python
for number in range(5):
    if number == 2:
        break
else:
    print("Number not found")
```

The `else` block does not execute because the loop terminated using `break`.

This is particularly useful for **search operations**.

---

# 12. Nested Loops and Conditions

Python allows loops inside other loops and conditions inside loops.

For example:

```python
numbers = [1, 2, 3, 4, 5]

for number in numbers:
    if number % 2 == 0:
        print(number, "is even")
```

Output:

```text
2 is even
4 is even
```

This pattern is extremely common in data processing.

---

# 13. Practical ML Example

Suppose we have prediction probabilities and want to classify them using a simple threshold:

```python
probabilities = [0.2, 0.8, 0.6, 0.3]

for probability in probabilities:
    if probability >= 0.5:
        print("Positive")
    else:
        print("Negative")
```

Output:

```text
Negative
Positive
Positive
Negative
```

In real ML projects, libraries such as NumPy and scikit-learn often provide vectorized or optimized operations for this kind of processing, but understanding Python control flow remains fundamental.

# 14. Important Python Feature: Indentation

Python uses **indentation to define code blocks**.

Correct:

```python
if age >= 18:
    print("Eligible")
```

Incorrect:

```python
if age >= 18:
print("Eligible")
```

The standard style is **4 spaces per indentation level**.

Indentation is therefore not just formatting in Python; it is part of the syntax.

## Common Mistakes

### 1. Using multiple `if` statements when `elif` is required

Consider:

```python
marks = 95

if marks >= 90:
    print("A")

if marks >= 80:
    print("B")
```

Both conditions are checked independently, so both can execute.

If only one category should be selected, use:

```python
if marks >= 90:
    print("A")
elif marks >= 80:
    print("B")
```

### 2. Creating an infinite `while` loop

This can run forever:

```python
i = 1

while i <= 5:
    print(i)
```

`i` never changes, so the condition never becomes false.

Correct:

```python
i = 1

while i <= 5:
    print(i)
    i += 1
```

### 3. Modifying a collection carelessly while iterating

Changing a list while directly iterating over it can lead to skipped elements or unexpected behavior. In such cases, iterate over a copy or build a new collection when appropriate.

## Interview Follow-up

**Q: When would you use `for` instead of `while`?**

Use `for` when iterating over an iterable or when the iteration is naturally tied to a sequence. Use `while` when repetition depends on a condition whose number of iterations may not be known beforehand.

**Q: What is the difference between `break` and `continue`?**

* `break` → terminates the entire loop.
* `continue` → skips the current iteration and continues with the next one.

**Q: What happens if an `if` condition is false and there is no `else`?**

Python simply skips that block and continues with the next statement.

### Interview Takeaway

> **`if`, `elif`, and `else` control decision-making, while `for` and `while` control repetition. `for` is generally used to iterate over an iterable, whereas `while` repeats as long as a condition remains true. `break` terminates a loop and `continue` skips the current iteration. Python uses indentation to define these blocks.**
