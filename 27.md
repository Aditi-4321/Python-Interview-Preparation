# Question 27 — What are `break`, `continue`, and `pass`?

## Answer

`break`, `continue`, and `pass` are Python control-flow statements. They are mainly used to control or structure the execution of loops and code blocks.

### 1. `break`

`break` **immediately terminates the nearest enclosing loop**.

#### Example

```python
for i in range(1, 6):
    if i == 4:
        break
    print(i)
```

**Output:**

```text
1
2
3
```

When `i` becomes `4`, `break` terminates the loop completely.

**Use when:** You have found what you were looking for or a condition means there is no reason to continue looping.

---

### 2. `continue`

`continue` **skips the remaining statements in the current iteration** and moves to the next iteration of the loop.

#### Example

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```

**Output:**

```text
1
2
4
5
```

When `i == 3`, the `print()` statement is skipped, but the loop continues.

**Use when:** You want to ignore certain values or conditions but continue processing the remaining data.

---

### 3. `pass`

`pass` is a **null statement**. It does nothing when executed.

It is useful when Python requires a statement syntactically, but you don't want to implement the logic yet.

#### Example

```python
for i in range(5):
    if i == 3:
        pass
    print(i)
```

**Output:**

```text
0
1
2
3
4
```

Unlike `continue`, `pass` does **not skip the iteration**. Execution simply moves to the next statement.

It is also commonly used while creating a function or class whose implementation will be added later:

```python
def preprocess_data():
    pass
```

```python
class MLModel:
    pass
```

---

## 🔍 Key Difference

| Statement  | What it does                   | Loop continues? |
| ---------- | ------------------------------ | --------------- |
| `break`    | Terminates the loop completely | ❌ No            |
| `continue` | Skips current iteration        | ✅ Yes           |
| `pass`     | Does nothing                   | ✅ Yes           |

### Simple way to remember

```text
break    → Stop the loop
continue → Skip this iteration
pass     → Do nothing
```

### ML-oriented example

Suppose you are processing records:

```python
for record in records:
    if record is None:
        continue

    if record == "STOP":
        break

    print(record)
```

Here:

* `continue` skips invalid/empty records.
* `break` stops processing when the stopping condition is reached.
* `pass` could be used when a condition intentionally has no action yet.

## Common Mistake

A common confusion is between `continue` and `pass`:

```python
if x == 0:
    continue
```

skips the rest of the current loop iteration.

But:

```python
if x == 0:
    pass
```

does nothing and execution continues with the next statement in the same iteration.

## Interview Takeaway

> **`break` terminates a loop, `continue` skips the current iteration, and `pass` is a placeholder that performs no operation.**

### Interview Follow-up

**Q: Can `break` and `continue` be used outside a loop?**
No. Using them outside an appropriate loop context raises a `SyntaxError`.

**Q: Does `pass` affect program execution?**
No. It is effectively a no-operation placeholder and does not change the normal flow of execution.

These three are worth remembering as a set because interviewers commonly ask for their differences together.
