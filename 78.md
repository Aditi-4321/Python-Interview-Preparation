# Question 78 — Solve a frequency-counting problem using a dictionary.

## Answer

A **dictionary** is commonly used for frequency counting because it stores each element as a **key** and its frequency as the **value**.

### Example: Count frequency of elements in a list

```python
def count_frequency(arr):
    freq = {}

    for x in arr:
        if x in freq:
            freq[x] += 1
        else:
            freq[x] = 1

    return freq


arr = [1, 2, 2, 3, 1, 2, 4, 3]

print(count_frequency(arr))
```

### Output

```text
{1: 2, 2: 3, 3: 2, 4: 1}
```

### How it works

For every element:

1. Check whether the element already exists as a dictionary key.
2. If it exists, increase its count by `1`.
3. Otherwise, create the key with frequency `1`.

For example:

```text
Input:  [1, 2, 2, 3, 1]

1 → {1: 1}
2 → {1: 1, 2: 1}
2 → {1: 1, 2: 2}
3 → {1: 1, 2: 2, 3: 1}
1 → {1: 2, 2: 2, 3: 1}
```

### Alternative using `get()`

The same logic can be written more concisely:

```python
def count_frequency(arr):
    freq = {}

    for x in arr:
        freq[x] = freq.get(x, 0) + 1

    return freq
```

Here, `freq.get(x, 0)` returns the current frequency of `x`. If `x` is not present, it returns `0`.

### String frequency example

The same technique can count characters:

```python
def char_frequency(s):
    freq = {}

    for ch in s:
        freq[ch] = freq.get(ch, 0) + 1

    return freq


s = "banana"

print(char_frequency(s))
```

**Output:**

```text
{'b': 1, 'a': 3, 'n': 2}
```

### Complexity

For `n` elements:

* **Time:** O(n) average
* **Space:** O(k), where `k` is the number of distinct elements.

Dictionary lookup and insertion are **O(1) average**.

### Why use a dictionary?

A dictionary is useful because we need to maintain a relationship:

```text
element → frequency
```

For example:

```text
2 → 3
3 → 2
4 → 1
```

This pattern is widely used in interview problems such as:

* Finding the most frequent element
* Finding the first non-repeating character
* Checking whether two strings are anagrams
* Counting words in a document
* Building frequency-based features for ML/data processing

### Common Mistake

Avoid repeatedly using `list.count()` inside a loop:

```python
for x in arr:
    print(x, arr.count(x))
```

This can become **O(n²)** because `count()` scans the list each time.

### Interview Follow-up

**Q: Why is a dictionary preferred for frequency counting?**

Because it provides average **O(1) lookup and update**, allowing us to count all elements in **O(n)** average time instead of repeatedly scanning the collection.

### Interview Takeaway

> The standard frequency-counting pattern is **dictionary + one-pass traversal**: store each element as a key and its frequency as the value.
