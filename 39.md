# Question 39 — What is abstraction?

## Answer

**Abstraction** is an Object-Oriented Programming (OOP) concept that means **hiding unnecessary implementation details and exposing only the essential functionality to the user**.

In simple terms:

> **Abstraction focuses on what an object does rather than how it does it.**

For example, when you use an ATM, you select options such as **withdraw money** or **check balance**. You do not need to know how the ATM internally communicates with the bank server, validates the transaction, or updates the database.

---

## Why is Abstraction Important?

### 1. Hides Complexity

Users do not need to understand the internal implementation.

### 2. Provides a Simple Interface

Only the necessary operations are exposed.

### 3. Improves Maintainability

Internal implementation can change without requiring changes to the code that uses the interface.

### 4. Reduces Coupling

The calling code depends on the exposed interface rather than the internal implementation.

### 5. Improves Security and Control

Sensitive or unnecessary implementation details can remain hidden from the user.

---

## Abstraction in Python

Python provides abstraction primarily through **abstract base classes (ABCs)** using the `abc` module.

```python id="1n5f2p"
from abc import ABC, abstractmethod


class Animal(ABC):

    @abstractmethod
    def sound(self):
        pass


class Dog(Animal):

    def sound(self):
        print("Bark")


dog = Dog()
dog.sound()
```

Here:

* `Animal` is an **abstract class**.
* `sound()` is an **abstract method**.
* `@abstractmethod` specifies that subclasses must provide an implementation.
* `Dog` implements `sound()`.
* We cannot normally create an instance of `Animal` directly because it contains an unimplemented abstract method.

```python id="p9u8x3"
animal = Animal()   # TypeError
```

The abstract class defines **what functionality must exist**, while the child class defines **how that functionality works**.

---

## How `ABC` and `@abstractmethod` Work

The `ABC` class provides the infrastructure for defining abstract base classes.

```python id="x0y3w7"
from abc import ABC, abstractmethod

class Model(ABC):

    @abstractmethod
    def predict(self, x):
        pass
```

Any concrete subclass should implement `predict()`:

```python id="c5z1r4"
class LinearModel(Model):

    def predict(self, x):
        return "Linear prediction"
```

Now:

```python id="9t4w6e"
model = LinearModel()
print(model.predict([1, 2, 3]))
```

The important idea is:

```text
Abstract class → defines required interface
Concrete class → provides implementation
```

## Abstraction vs Encapsulation

These concepts are often confused.

| Concept           | Main Focus                                                              |
| ----------------- | ----------------------------------------------------------------------- |
| **Abstraction**   | Hides unnecessary implementation details                                |
| **Encapsulation** | Bundles data and methods together and controls access to internal state |

For example:

* **Abstraction:** You call `model.predict(data)` without knowing how prediction is internally calculated.
* **Encapsulation:** The model keeps its internal parameters and operations together and controls how they are accessed.

They often work together in well-designed software.

---

## Abstraction in Machine Learning

Abstraction is heavily used in ML libraries.

For example, a model can expose a simple interface:

```python
model.fit(X_train, y_train)
model.predict(X_test)
```

The user does not need to manually implement every internal operation involved in optimization, parameter updates, or prediction.

Different models can provide the same high-level operations:

```text
Model
 ├── Linear Regression
 ├── Decision Tree
 └── Neural Network
```

Each model can implement `fit()` and `predict()` differently while providing a consistent interface to the user.

This makes it easier to build reusable ML pipelines.

---

## Common Mistakes

* **Abstraction does not mean hiding all information.** It hides unnecessary implementation details while exposing what the user needs.
* Do not confuse abstraction with encapsulation.
* An abstract class is not necessarily a completely implementation-free class; it can contain concrete methods and attributes as well.
* `@abstractmethod` specifies a required interface, but the abstract method can technically contain an implementation that subclasses may extend or override.
* Abstraction is a **design concept**, while `ABC` and `@abstractmethod` are Python mechanisms that help implement it.

## Interview Follow-up

**1. What is an abstract class?**
An abstract class is a class intended to serve as a common interface or base for subclasses. In Python, it can be created using `ABC` and may contain abstract methods.

**2. What is an abstract method?**
An abstract method is a method declared as required for concrete subclasses to implement, typically using `@abstractmethod`.

**3. Can an abstract class have normal methods?**
Yes. An abstract class can contain both abstract methods and concrete methods.

### Interview Takeaway

> **“Abstraction is the OOP principle of hiding unnecessary implementation details and exposing only the essential functionality. In Python, abstraction can be implemented using abstract base classes through the `abc` module, where `ABC` and `@abstractmethod` help define a common interface for subclasses.”**
