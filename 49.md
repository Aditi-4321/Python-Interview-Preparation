# Question 49 — What is an iterable?

## Answer

An **iterable** is any Python object whose elements can be accessed one at a time, typically by using a `for` loop.

In simple terms:

> **An iterable is an object that can provide its elements one by one.**

Examples of common iterables include:

* Lists
* Tuples
* Strings
* Sets
* Dictionaries
* Ranges
* Files
* Generators

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)
```

Here, `numbers` is an iterable because Python can retrieve its elements one by one.

---

## 1. How Does an Iterable Work?

Python's iteration protocol is based mainly on two concepts:

* `__iter__()`
* `__next__()`

An **iterable** normally provides an `__iter__()` method that returns an **iterator**.

```python
numbers = [10, 20, 30]

it = iter(numbers)

print(next(it))  # 10
print(next(it))  # 20
print(next(it))  # 30
```

After all elements have been consumed:

```python
next(it)
```

raises:

```text
StopIteration
```

So the relationship is:

```text
Iterable
   ↓ iter()
Iterator
   ↓ next()
Next element
   ↓
Next element
   ↓
StopIteration
```

---

## 2. Iterable vs Iterator

These two terms are closely related but are **not the same**.

### Iterable

An iterable is an object that can produce an iterator.

```python
numbers = [10, 20, 30]

it = iter(numbers)
```

### Iterator

An iterator is an object that keeps track of the current position and provides the next element using `next()`.

```python
print(next(it))
print(next(it))
```

An iterator implements both:

```python
__iter__()
__next__()
```

A useful interview statement is:

> **Every iterator is iterable, but not every iterable is an iterator.**

For example:

```python
numbers = [1, 2, 3]

print(hasattr(numbers, "__iter__"))  # True
print(hasattr(numbers, "__next__"))  # False
```

The list is iterable but is not itself an iterator.

---

## 3. Why Does `for` Work with Iterables?

When Python executes:

```python
for x in numbers:
    print(x)
```

conceptually, it does something similar to:

```python
it = iter(numbers)

while True:
    try:
        x = next(it)
        print(x)
    except StopIteration:
        break
```

This is a simplified model of what happens internally.

Therefore, `for` loops don't require the object to be a list. They require the object to support the iteration protocol.

---

## 4. Examples of Iterables

### List

```python
numbers = [1, 2, 3]

for x in numbers:
    print(x)
```

### Tuple

```python
values = (10, 20, 30)

for x in values:
    print(x)
```

### String

```python
name = "Python"

for char in name:
    print(char)
```

A string is iterable character by character.

### Dictionary

```python
student = {
    "name": "Aditi",
    "age": 22
}

for key in student:
    print(key)
```

By default, iterating over a dictionary produces its **keys**.

You can iterate over values:

```python
for value in student.values():
    print(value)
```

Or key-value pairs:

```python
for key, value in student.items():
    print(key, value)
```

### Range

```python
for number in range(5):
    print(number)
```

`range` is iterable and is also memory-efficient because it doesn't need to store all generated numbers as a list.

---

## 5. Iterable and Memory Efficiency

One important reason iterables are useful is that iteration does not necessarily require all data to be stored in memory at once.

For example:

```python
for line in open("large_file.txt"):
    process(line)
```

The file can be processed incrementally instead of loading the entire file into memory.

This is particularly useful when working with:

* Large datasets
* Log files
* Data preprocessing
* ML pipelines
* Streaming data

---

## 6. Iterable vs Generator

A **generator is a type of iterator**, while an iterable is the broader concept.

For example:

```python
def numbers():
    yield 1
    yield 2
    yield 3
```

Calling:

```python
g = numbers()
```

creates a generator object.

It can be iterated lazily:

```python
for x in g:
    print(x)
```

Generators are especially useful when data should be produced **on demand** rather than stored completely in memory.

---

## 7. Creating a Custom Iterable

A class can be made iterable by implementing `__iter__()`.

```python
class Numbers:
    def __init__(self):
        self.data = [10, 20, 30]

    def __iter__(self):
        return iter(self.data)


numbers = Numbers()

for x in numbers:
    print(x)
```

Output:

```text
10
20
30
```

Here, `Numbers` is an iterable because it provides `__iter__()`.

---

## 8. Why Are Iterables Important in Python?

Iterables provide a common interface for processing different kinds of data.

The same `for` loop can work with:

```python
list
tuple
set
string
dictionary
range
file
generator
```

This is one reason Python code can be concise and flexible.

In ML/data-processing code, iterables are frequently used for:

```text
Dataset
   ↓
Iteration
   ↓
Preprocessing
   ↓
Batching
   ↓
Model Training
```

For example, a dataset can be processed batch by batch rather than loading everything into memory.

## Common Mistakes

### 1. Saying iterable and iterator are the same

They are not.

```text
Iterable → can provide an iterator
Iterator → produces the next item
```

### 2. Assuming every iterable supports indexing

Not true.

For example:

```python
numbers = {10, 20, 30}
```

A set is iterable but does not support:

```python
numbers[0]
```

### 3. Assuming iterables always store all elements

They don't necessarily.

Generators, files, and `range` can provide elements without storing a complete collection in the same way a list does.

---

## Interview Takeaway

> **An iterable is an object that can be iterated over, usually by providing an `__iter__()` method. Calling `iter()` on an iterable produces an iterator, and the iterator provides elements through `next()` until `StopIteration` occurs.**

### Key Relationship

```text
Iterable
   │
   │ iter()
   ↓
Iterator
   │
   │ next()
   ↓
Elements
   │
   ↓
StopIteration
```

**Most important interview point:**

> **Every iterator is iterable, but every iterable is not necessarily an iterator.**
